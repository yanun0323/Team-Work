## 新功能

**實驗功能：依意思搜尋**
員工現在可以依程式碼的意思搜尋專案，不只比對字面。問「我們把使用者設定存在哪裡」，就算那些檔案從沒用過這些字，也能找到對的檔案。它在你 Mac 的神經網路引擎上執行，資料不會離開你的電腦。預設關閉：在設定裡打開，然後重新啟動 App（App 可以幫你重開）。需要 Apple 晶片上的 macOS 27，只有能跑的 Mac 才會出現這個開關。第一次會下載模型並讀過你的專案；在那之前，或出了任何問題時，會悄悄改用一般的關鍵字搜尋。

**人力資源公司改名為移民署**
同一個地方、同一份工作，換了新名字。

**島上的滑過效果更乾淨**
指向公司、機場、基地台或移民署時，現在只會讓建築本身的形狀變暗，不會在零件重疊處出現更暗的色塊。公司的整塊用地都會回應游標，包括屋簷下的地面。
