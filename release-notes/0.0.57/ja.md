## 新機能

**試験機能：意味で検索**
社員は、コードに書かれた言葉だけでなく、コードの意味でプロジェクトを探せるようになりました。「ユーザーの設定を保存しているところ」と聞けば、その言葉がまったく使われていなくても正しいファイルを見つけます。Mac の Neural Engine で動くので、データがコンピュータの外に出ることはありません。既定ではオフです。設定でオンにしてからアプリを再起動してください（アプリが再起動してくれます）。Apple シリコンの macOS 27 が必要で、動かせる Mac にだけスイッチが表示されます。初回はモデルをダウンロードしてプロジェクトを読み込みます。それが終わるまで、または何か問題があったときは、静かに普通のキーワード検索に切り替わります。

**人材派遣会社は入国管理局になりました**
場所も仕事も同じで、名前だけが変わりました。

**島でのマウスオーバーがすっきり**
会社、空港、基地局、入国管理局を指すと、建物そのものの形だけが暗くなり、部品が重なるところにさらに暗いまだらが出なくなりました。会社の敷地全体が、ひさしの下の地面も含めてポインタに反応します。
