## 新功能

**给任务做一次性的流程**
- 创建任务时，把流程切到“自定义”，就能当场排好步骤。
- 可以从空白步骤开始，或导入一份任务蓝图再修改。
- 点步骤就能编辑。这个流程只属于这个任务；想重复使用就点“存成任务蓝图”。

**任务出现在对话里**
- 从对话创建的任务，会以卡片显示在它来源那条消息下面。
- 点卡片打开任务。再次打开对话时，卡片还在。

**会议里的技能**
- 在会议里输入 `$`，会列出对话里所有人的技能，不只一个人的。
- 那一轮回答的每个人都会拿到同一个技能。

**内置员工蓝图更少、更清楚**
- 全栈工程师并进了通才。原本用它的员工会自动换过去。
- 新增：Matt Pocock 和 Poteto，用他们作者在 GitHub 上公开的技能工作。

**小修复**
- 下方空间不够时，长的下拉菜单会往上展开。
- 在每日图表的柱子上方移动鼠标，可以看到那天的总数。
- 用量上限刷新得更频繁，而且不必每次都去问供应商。
