## 新功能

**替任務做一次性的流程**
- 建立任務時，把流程切到「自訂」，就能當場排好步驟。
- 可以從空白步驟開始，或匯入一份任務藍圖再修改。
- 點步驟就能編輯。這個流程只屬於這個任務；想重複使用就按「存成任務藍圖」。

**任務出現在對話裡**
- 從對話建立的任務，會以卡片顯示在它來源那則訊息下面。
- 點卡片打開任務。再次打開對話時，卡片還在。

**會議裡的技能**
- 在會議裡打 `$`，會列出對話裡所有人的技能，不只一個人的。
- 那一輪回答的每個人都會拿到同一個技能。

**內建員工藍圖更少、更清楚**
- 全端工程師併進了通才。原本用它的員工會自動換過去。
- 新增：Matt Pocock 和 Poteto，用他們作者在 GitHub 上公開的技能工作。

**小修正**
- 下方空間不夠時，長的下拉選單會往上開。
- 在每日圖表的長條上方移動滑鼠，可以看到那天的總數。
- 用量上限更新得更頻繁，而且不必每次都去問供應商。
