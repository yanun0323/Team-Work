## 新機能

**タスクだけのフローを作る**
- タスクを作るとき、フローを「カスタム」に切り替えれば、その場でステップを並べられます。
- 空のステップから始めるか、ワークフローを読み込んで手を加えます。
- ステップをクリックすると編集できます。このフローはそのタスクだけのものです。使い回したいときは「ワークフローとして保存」を押します。

**タスクがチャットに表示されます**
- チャットから作ったタスクは、もとのメッセージの下にカードとして表示されます。
- カードをクリックするとタスクが開きます。チャットを開き直してもカードは残っています。

**ミーティングでのスキル**
- ミーティングで `$` と入力すると、一人分ではなく、チャットにいる全員のスキルが並びます。
- その回に答える全員が同じスキルを受け取ります。

**組み込みブループリントを少なく、わかりやすく**
- フルスタックエンジニアはジェネラリストにまとめました。使っていた社員は自動で移ります。
- 新登場：Matt Pocock と Poteto。作者が GitHub で公開しているスキルで働きます。

**小さな修正**
- 下に余裕がないとき、長いドロップダウンは上に開きます。
- 日ごとのグラフで棒の上にマウスを置くと、その日の合計が見られます。
- 使用量の上限が、毎回プロバイダーに問い合わせることなく、より頻繁に更新されます。
