## 새로운 기능

**채팅 ID를 클릭 한 번으로 복사**
채팅 ID가 입력창 왼쪽 아래에 보입니다. 클릭하면 복사되니 필요한 곳에 붙여 넣으세요.

**프로젝트 크기 보기**
회사 머리글의 브랜치 이름 바로 옆에 프로젝트가 차지하는 공간이 보입니다.

**긴 선택지가 채팅을 밀어내지 않습니다**
직원이 긴 선택지 목록을 주면 목록이 자기 상자 안에서 스크롤됩니다. 위의 대화는 계속 보입니다.

## 수정

**직원은 고르라고 하기 전에 설명합니다**
직원이 제대로 된 설명 없이 버튼 몇 개만 보여 줄 때가 있었습니다. 이제 버튼이 나타나기 전에 답, 제안, 묻는 내용을 꼭 적어야 합니다. 나중에 채팅을 이어받는 동료도 그 설명을 볼 수 있습니다.
