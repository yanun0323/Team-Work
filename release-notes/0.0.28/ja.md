## 新機能

**チャットの ID をワンクリックでコピー**
チャットの ID が入力欄の左下に表示されるようになりました。クリックするとコピーされるので、必要なところに貼り付けられます。

**プロジェクトの大きさを見る**
会社のヘッダーで、ブランチ名のすぐ横にプロジェクトの使っている容量が表示されます。

**長い選択肢がチャットを押し出しません**
社員が長い選択肢の一覧を出したとき、一覧は専用の枠の中でスクロールします。上の会話は見えたままです。

## 修正

**社員は選んでもらう前に説明します**
社員がちゃんと説明せずにボタンをいくつか出すだけのことがありました。今はボタンが出る前に、答え、提案、聞きたいことを必ず書きます。あとでチャットを引き継ぐ同僚もその説明を読めます。
