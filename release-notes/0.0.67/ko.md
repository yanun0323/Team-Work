## 새로운 기능

**더 똑똑한 메모리 검색**
직원이 메모리를 찾아볼 때, 이제 정확한 단어만이 아니라 의미로 메모를 찾습니다. '배포'로 검색하면 '프로덕션에 출시하기'에 관한 메모도 나옵니다. Mac에 시맨틱 검색이 준비되어 있을 때 동작하며, 그렇지 않으면 단어 일치로 돌아가는데 이것도 이제 중국어를 더 잘 다룹니다.

**읽기 전용 스크립트 도구(실험 기능)**
공항의 실험 설정에 새 스위치가 생겼습니다. 직원이 짧은 스크립트로 파일 읽기, 코드 검색 같은 여러 번의 조회를 한 단계로 묶고 요약만 돌려줄 수 있습니다. 읽기만 하고 아무것도 바꾸지 않으며, 켜지 않으면 꺼져 있습니다.
