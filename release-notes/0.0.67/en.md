## What's new

**Smarter memory search**
When employees look through memory, they now find notes by what they mean, not only by the exact words. A search for "deploy" can turn up a note about "releasing to production". This works once semantic search is set up on your Mac; otherwise it falls back to word matching, which now also handles Chinese text better.

**Read-only script tool (experimental)**
A new switch in the airport's experimental settings lets employees run a short script that combines several look-ups (reading files, searching code and so on) in one step and hands back only the summary. It can only read, never change anything, and it's off unless you turn it on.
