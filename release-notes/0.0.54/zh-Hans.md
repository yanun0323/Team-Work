## 新功能

**控制谁能在你的岛上做什么**
配对的电脑现在默认只能看。你可以给每一台决定能不能也做修改。你的基站会列出谁正在访问、开着什么，他们的建筑在地图上会被框起来。你可以请访客离开，或屏蔽他一小时、直到你解除为止。也可以设置其他电脑看到的你的名字。

**Claude 在 Team Work 里登录**
Claude 现在在 Team Work 里有自己的登录，和终端里的 `claude` 命令分开。点“登录 Claude”，在浏览器里完成。登录过期时，Team Work 会在启动时发现，在员工碰到问题前请你重新登录。

**长任务能继续下去**
任务步骤或任务负责人累积的对话超过模型读得下的量时，前面的部分会被摘要，工作继续，而不是失败。

**模型调用更快、更便宜**
Claude 员工会从上次停下的地方接着做，不必每次重来；ChatGPT 和 OpenAI 密钥也会重复使用更多已经读过的内容。回复来得更快、用的 token 更少。回复五分钟没动静时，会停下来重试，不会一直挂着。

**在员工页面看他的员工蓝图**
员工页面现在会显示他所用的员工蓝图，可以从那里打开。

## 修复

- 在对话里往上滚，即使只滚一点点，新消息进来时也不会再跳回最底下。“最新”按钮会平滑地滚回去。
- 任务卡片的进度单独一行，放在 token 数上面。
- 在创建分支时停止任务，不会再让分支坏掉。
