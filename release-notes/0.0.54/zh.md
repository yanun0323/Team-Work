## 新功能

**控制誰能在你的島上做什麼**
配對的電腦現在預設只能看。你可以替每一台決定能不能也做修改。你的基地台會列出誰正在拜訪、開著什麼，他們的建築在地圖上會被框起來。你可以請訪客離開，或封鎖他一小時、直到你解除為止。也可以設定別的電腦看到的你的名字。

**Claude 在 Team Work 裡登入**
Claude 現在在 Team Work 裡有自己的登入，和終端機裡的 `claude` 指令分開。按「登入 Claude」，在瀏覽器裡完成。登入過期時，Team Work 會在啟動時發現，在員工碰到問題前請你重新登入。

**長任務能繼續下去**
任務步驟或任務負責人累積的對話超過模型讀得下的量時，前面的部分會被摘要，工作繼續，而不是失敗。

**模型呼叫更快、更便宜**
Claude 員工會從上次停下的地方接著做，不必每次重來；ChatGPT 和 OpenAI 金鑰也會重複使用更多已經讀過的內容。回覆來得更快、用的 token 更少。回覆五分鐘沒動靜時，會停下來重試，不會一直掛著。

**在員工頁面看他的員工藍圖**
員工頁面現在會顯示他所用的員工藍圖，可以從那裡打開。

## 修正

- 在對話裡往上捲，就算只捲一點點，新訊息進來時也不會再跳回最底下。「最新」按鈕會順順地捲回去。
- 任務卡片的進度單獨一行，放在 token 數上面。
- 在建立分支時停止任務，不會再讓分支壞掉。
