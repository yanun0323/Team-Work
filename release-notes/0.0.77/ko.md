## 새 기능

**Code Mode가 기본으로 켜져요**
설정을 바꾸지 않아도 직원이 한 단계에서 여러 도구를 사용할 수 있어요. 이미 Code Mode를 꺼 두었다면 그대로 유지돼요.

**저장된 메모를 더 찾아볼 수 있어요**
직원은 검색어와 일치하는 메모를 다섯 개씩 읽어요. 처음 다섯 개에서 답을 찾지 못하면 다음 메모를 살펴볼 수 있어요.

**OpenAI 채팅의 기본 용량이 달라졌어요**
OpenAI 모델이 한 번에 읽을 수 있는 양을 알려 주지 않으면, Team Work는 기존 27만 2천 토큰 대신 100만 토큰을 기준으로 채팅에 남은 공간을 추정해요.
