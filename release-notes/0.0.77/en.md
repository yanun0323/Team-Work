## What's new

**Code Mode is on by default**
Employees can use several tools in a single step without you turning on Code Mode first. If you already turned it off, it stays off.

**Search more saved notes**
Employees now read five matching notes at a time and can keep looking if the first five don't have the answer.

**A new default for OpenAI chats**
When an OpenAI model doesn't report how much text it can read at once, Team Work now uses one million tokens instead of 272,000 to estimate how much room is left in the chat.
