## 새로운 기능

**기지국을 열면 지지직 소리가 납니다**
기지국을 열면 이제 전류가 흐르는 짧은 윙 소리가 납니다. 설정의 다른 건물 소리와 같은 '건물 열기' 스위치로 켜고 끕니다.

**멈춘 책임자에게 쓰면 다시 움직입니다**
작업 책임자가 주고받는 질문, 되돌려 보내기, 실패한 실행 횟수의 한도에 걸려 멈추면, 이제 '책임자가 계속하게 하기'를 먼저 누를 필요가 없습니다: 그냥 책임자에게 쓰면 여러분의 메시지에서 이어 갑니다. 비용 한도에서 멈췄다면 여전히 예산 질문에 먼저 답해야 합니다.

## 수정

- 주소나 키를 바꾼 뒤처럼 직원이 쓰는 모델을 공급자가 더 이상 제공하지 않아도 앱이 시작에 실패하지 않습니다. 그 직원은 다른 모델을 고를 때까지 설정을 유지합니다.
