## 新功能

**隱藏用不到的員工藍圖和任務藍圖**
- 員工藍圖和任務藍圖多了眼睛按鈕。隱藏後，從清單挑選時就不會再出現。
- 已經在用的人照樣保留。在設定裡，隱藏的項目仍留在清單上、變淡顯示，可以再打開。

**對話知道模型記得住多少**
- 每個供應商現在有 context window（模型一次能讀進多少文字）。Anthropic 和 OpenAI 已經幫你填好；其他供應商可以自己設定，有 128K、256K 和 1M 的捷徑。
- 長對話會依這個大小在適當的時候摘要，什麼時候摘要可以在設定裡調。
- 對話框會顯示下一則訊息會佔滿多少。

## 修正

- **在終端機打中文或日文：** 選字時按的 Shift+Enter 等按鍵，會留在輸入法裡，不會被送進 shell。
- **舊的 Mac：** App 現在需要 macOS 13.3 以上。以前在舊版系統上會打開一個空白視窗；現在 macOS 會直接說明無法執行。
