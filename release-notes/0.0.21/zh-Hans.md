## 新功能

**隐藏用不到的员工蓝图和任务蓝图**
- 员工蓝图和任务蓝图多了眼睛按钮。隐藏后，从列表挑选时就不会再出现。
- 已经在用的人照样保留。在设置里，隐藏的项目仍留在列表上、变淡显示，可以再打开。

**对话知道模型记得住多少**
- 每个供应商现在有 context window（模型一次能读进多少文字）。Anthropic 和 OpenAI 已经帮你填好；其他供应商可以自己设置，有 128K、256K 和 1M 的快捷选项。
- 长对话会根据这个大小在合适的时候摘要，什么时候摘要可以在设置里调。
- 对话框会显示下一条消息会占满多少。

## 修复

- **在终端输入中文或日文：** 选词时按的 Shift+Enter 等按键，会留在输入法里，不会被发送到 shell。
- **旧的 Mac：** App 现在需要 macOS 13.3 及以上。以前在旧版系统上会打开一个空白窗口；现在 macOS 会直接说明无法运行。
