## 新機能

**使わないブループリントとフローを隠す**
- ブループリントとタスクのフローに目のボタンが付きました。隠すと、一覧から選ぶときに出てこなくなります。
- すでに使っている人はそのまま使えます。設定では、隠したものも薄く表示されたまま一覧に残るので、また表示できます。

**チャットはモデルがどれだけ覚えられるかを知っています**
- 各プロバイダーにコンテキストウインドウ（モデルが一度に読み込めるテキストの量）ができました。Anthropic と OpenAI は入力済みです。ほかは自分で設定でき、128K、256K、1M のショートカットがあります。
- 長いチャットはそのサイズに合わせてちょうどいいときに要約され、タイミングは設定で調整できます。
- チャットの入力欄に、次のメッセージでどれだけいっぱいになるかが表示されます。

## 修正

- **ターミナルで中国語や日本語を入力するとき：** 変換中に押した Shift+Enter などのキーは、シェルに送られずに入力メソッドに残ります。
- **古い Mac：** アプリには macOS 13.3 以降が必要になりました。古いバージョンでは真っ白なウインドウが開いていましたが、今は macOS が実行できないと伝えます。
