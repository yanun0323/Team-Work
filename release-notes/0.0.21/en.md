## What's new

**Hide blueprints and flows you don't use**
- Blueprints and task flows now have an eye button. Hide one and it stops showing up when you pick from a list.
- Anyone already using it keeps it. In Settings, hidden ones stay in the list, faded, so you can show them again.

**Chats know how much the model can remember**
- Each provider now has a context window (how much text the model can take in at once). Anthropic and OpenAI are filled in for you; for others you can set it, with 128K, 256K and 1M shortcuts.
- Long chats get summarized at the right time based on that size, and you can tune when in Settings.
- The chat box shows how full the next message will be.

## Fixes

- **Typing Chinese or Japanese in the terminal:** keys like Shift+Enter pressed while picking a word now stay with your input method instead of going to the shell.
- **Older Macs:** the app now needs macOS 13.3 or later. On older versions it used to open to a blank window; now macOS just says it can't run.
