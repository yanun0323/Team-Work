## 새로운 기능

**긴 채팅이 빨리 열립니다**
기록이 긴 채팅은 이제 최근 메시지 100개만 보여 주며 열립니다. 더 앞을 보고 싶다면 맨 위의 '이전 메시지 보기'를 누르면 100개를 더 불러오고, 보던 위치는 그대로입니다. 아무것도 지워지지 않고 모두 저장되어 있습니다.

**메모리도 헛일도 줄었습니다**
앱이 시작할 때 모든 채팅의 전체 기록을 불러오지 않습니다. 채팅에 정말 필요할 때만 읽고, 다 쓰면 놓아 줍니다. 시계가 1초 지날 때마다 화면 전체를 다시 그리던 것도 멈춰서, 아무것도 하지 않을 때는 더 조용합니다.

**문제 해결을 위한 메모리 점검**
앱이 메모리를 너무 많이 쓰는 것 같을 때를 위해, 기본으로 꺼져 있는 스위치를 켜면 내 컴퓨터에서 메모리 스냅숏을 뜰 수 있습니다. 내 컴퓨터에서만 접근할 수 있고 켰을 때만 동작합니다.
