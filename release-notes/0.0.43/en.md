## What's new

**Flying to another island is much quicker**
The plane now takes off faster, climbs straight up to a higher speed, and lands on the new island sooner. The whole trip takes about 5 seconds instead of about 9.

**The next island starts loading as soon as you take off**
Before, the new island only started loading once the old one had gone off the screen, and the plane circled over the sea while it waited. Now it starts loading the moment you leave, so it's usually ready by the time you get there. If you've been to that island before, you also no longer wait for the building heights to come in again: it uses the ones from last time and updates them quietly afterwards.

## Fixes

**Chats stay at the bottom**
When something like "loading" appeared above the messages, a chat could stop following new messages and stay stuck partway up. It now keeps following them.
