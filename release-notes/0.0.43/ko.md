## 새로운 기능

**다른 섬으로 훨씬 빨리 갑니다**
비행기가 더 빨리 뜨고, 곧장 더 빠른 속도로 올라가며, 새 섬에 더 일찍 내립니다. 전체 비행이 약 9초에서 약 5초가 되었습니다.

**뜨자마자 다음 섬을 불러옵니다**
전에는 이전 섬이 화면에서 사라진 뒤에야 새 섬을 불러오기 시작해, 비행기가 바다 위를 맴돌며 기다렸습니다. 이제 떠나는 순간 불러오기 시작하므로 도착할 무렵에는 대개 준비가 되어 있습니다. 전에 가 본 섬이라면 건물 높이가 다시 올 때까지 기다리지도 않습니다: 지난번 값을 쓰고 나중에 조용히 갱신합니다.

## 수정

**채팅이 맨 아래에 머뭅니다**
메시지 위에 '불러오는 중' 같은 것이 나타나면 채팅이 새 메시지를 따라가지 않고 중간에 멈춰 있을 수 있었습니다. 이제 계속 따라갑니다.
