## 新功能

**關掉視窗不會結束 App**
關掉視窗只是把它收起來。你的公司照樣工作，通知和 Dock 標記也照常出現。點 Dock 圖示就能把視窗叫回來，或用新的「視窗」選單裡的「最小化」（⌘M）和「關閉視窗」（⌘W）。真的要結束請按 ⌘Q。

**Team Work 住在選單列裡**
視窗關著時，Dock 圖示會消失，選單列上會有一個小圖示，顯示有幾件事在等你。從那裡可以打開視窗、檢查更新或結束。從選單列、Finder 或通知再次打開視窗時，Dock 圖示就會回來。
