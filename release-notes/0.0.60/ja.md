## 新機能

**ウインドウを閉じてもアプリは終了しません**
ウインドウを閉じても、しまうだけです。会社は働き続け、通知と Dock のバッジも届きます。Dock のアイコンをクリックするとウインドウが戻ります。新しい「ウインドウ」メニューの「しまう」（⌘M）と「ウインドウを閉じる」（⌘W）も使えます。本当に終了するには ⌘Q を使ってください。

**Team Work はメニューバーにいます**
ウインドウを閉じている間は Dock のアイコンが消え、メニューバーの小さなアイコンに待っている件数が出ます。そこからウインドウを開いたり、アップデートを確認したり、終了したりできます。メニューバー、Finder、通知からウインドウを開き直すと、Dock のアイコンが戻ります。
