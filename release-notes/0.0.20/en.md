## What's new

**Check for updates right now**
- Sources have a refresh button next to their version. Press it to check for a new version without waiting for the 6-hour check.

**Open folders in Finder**
- Hover over a folder in the Files tab and a button appears to open it in Finder.

**Map and stats**
- If you click a spot where a new company can't go, the map tells you why.
- The building grid is easier to see.
- The usage table shows each model's share of tokens.

**Fixes**
- Stopping a reply now leaves a note in the chat, and you can retry it.
- If the app restarts in the middle of a meeting, the reply that got cut off is marked so you can retry it, and everyone else still gets their turn.
- Skill sources on GitHub get the right version when a repo has similar branch names, like `main` and `changeset-release/main`.
- A source no longer looks missing just because you were offline for a moment.
- Pressing Backspace outside a text box no longer leaves the window stuck on the startup screen.
- When an employee asks you a question, it now explains what it found first, so the choices make sense.

**Help**
- The airport's chat and stats each have their own help page now, with fresh screenshots.
- Help pages start with a short summary, then the details.
