## 새로운 기능

**지금 바로 업데이트 확인**
- 소스의 버전 옆에 새로 고침 버튼이 생겼습니다. 누르면 6시간마다의 확인을 기다리지 않고 새 버전을 확인합니다.

**Finder에서 폴더 열기**
- 파일 탭에서 폴더 위에 마우스를 올리면 Finder에서 여는 버튼이 나타납니다.

**지도와 통계**
- 새 회사를 지을 수 없는 곳을 클릭하면 지도가 이유를 알려 줍니다.
- 건물 격자가 더 잘 보입니다.
- 사용량 표에 모델별 토큰 비율이 보입니다.

**수정**
- 답변을 멈추면 채팅에 메모가 남고, 다시 시도할 수 있습니다.
- 회의 도중 앱이 다시 시작되면, 끊긴 답변이 표시되어 다시 시도할 수 있고 다른 사람들도 여전히 차례가 옵니다.
- `main`과 `changeset-release/main`처럼 비슷한 브랜치 이름이 있는 repo에서도 GitHub 스킬 소스가 올바른 버전을 가져옵니다.
- 잠시 오프라인이었을 뿐인데 소스가 사라진 것처럼 보이지 않습니다.
- 텍스트 상자 밖에서 Backspace를 눌러도 창이 시작 화면에 멈춰 있지 않습니다.
- 직원이 질문할 때 먼저 찾은 것을 설명하므로 선택지가 이해됩니다.

**도움말**
- 공항의 채팅과 통계에 각각 새 스크린숏이 있는 도움말 페이지가 생겼습니다.
- 도움말 페이지는 짧은 요약으로 시작한 뒤 자세한 내용이 이어집니다.
