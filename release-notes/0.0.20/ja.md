## 新機能

**今すぐアップデートを確認**
- ソースのバージョンの横に更新ボタンが付きました。押すと、6 時間ごとの確認を待たずに新しいバージョンを確認します。

**Finder でフォルダを開く**
- ファイルタブでフォルダにマウスを置くと、Finder で開くボタンが出ます。

**地図と統計**
- 新しい会社を置けない場所をクリックすると、地図が理由を教えます。
- 建物のグリッドが見やすくなりました。
- 使用量の表に、モデルごとのトークンの割合が出ます。

**修正**
- 返信を止めるとチャットにメモが残り、再試行できます。
- ミーティングの途中でアプリが再起動しても、途切れた返信に印が付いて再試行でき、ほかの人にも順番が回ります。
- `main` と `changeset-release/main` のように似た名前のブランチがある repo でも、GitHub のスキルソースが正しいバージョンを取得します。
- 少しオフラインになっただけで、ソースが見つからないように見えることはなくなりました。
- テキスト欄の外で Backspace を押しても、ウインドウが起動画面のまま動かなくなることはなくなりました。
- 社員があなたに質問するときは、まず見つけたことを説明するので、選択肢の意味がわかります。

**ヘルプ**
- 空港のチャットと統計に、それぞれ新しいスクリーンショット付きのヘルプページができました。
- ヘルプページは短い要約から始まり、続いて詳細が来ます。
