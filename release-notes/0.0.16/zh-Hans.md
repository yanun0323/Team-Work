## 新功能

**说实话的进度条**
- 步骤很长时，进度条以前会冲到 90% 然后停住。现在会用更稳定的速度前进，更看得出步骤实际做到哪里。

**小镇画面正确了**
- 忙碌动画（大喊、飞舞的钞票）不会再穿过挡在前面的大楼。

**密钥和文件更安全**
- 工具日志里的 API 密钥和密码会被遮住，只显示最后 4 个字符。
- 改了供应商的地址时，保存的密钥要等你同意这个改动后，才会发到新地址。
- 保存失败时，所有东西都会回到原来的样子，密钥也是，不会只存一半。
- 错误的设置（不认识的供应商类型、奇怪的地址、负的价格、坏掉的流程）会在保存前被拦下，App 一定能顺利重新启动。
- 项目或技能不能再用快捷链接，让 App 读写自己文件夹以外的文件。
- 删除任务时，只会删掉那个任务创建的分支，你原本就有的分支不会动。
