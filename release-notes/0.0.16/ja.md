## 新機能

**正直な進捗バー**
- 長いステップでは、バーが 90% まで急いで進んでそこで止まっていました。今は落ち着いたペースで進むので、ステップが実際どこまで進んだかがわかりやすくなりました。

**町の表示が正しく**
- 忙しいときのアニメーション（叫び声や飛ぶお札）が、手前のビルを透けて見えなくなりました。

**キーとファイルをより安全に**
- ツールのログに出る API キーとパスワードは隠され、最後の 4 文字だけが表示されます。
- プロバイダーのアドレスを変えたとき、保存したキーは変更をあなたが承認するまで新しいアドレスに送られません。
- 保存に失敗したときは、キーも含めてすべて元に戻ります。中途半端に保存されることはありません。
- おかしな設定（知らないプロバイダーの種類、変なアドレス、マイナスの価格、壊れたフロー）は保存前に止められるので、アプリは必ずきちんと起動し直せます。
- プロジェクトやスキルが、ショートカットのリンクを使って自分のフォルダの外のファイルをアプリに読み書きさせることはできなくなりました。
- タスクを削除すると、そのタスクが作ったブランチだけが消えます。もともとあったブランチはそのままです。
