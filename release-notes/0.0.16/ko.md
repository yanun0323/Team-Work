## 새로운 기능

**정직한 진행 막대**
- 긴 단계에서 막대가 90%까지 급히 올라간 뒤 멈춰 있곤 했습니다. 이제 더 고른 속도로 움직여서 단계가 실제로 얼마나 진행됐는지 알기 쉽습니다.

**마을 화면이 제대로 보입니다**
- 바쁠 때의 애니메이션(외치기, 날아다니는 지폐)이 앞에 선 건물을 뚫고 보이지 않습니다.

**키와 파일이 더 안전해졌습니다**
- 도구 로그의 API 키와 비밀번호는 가려지고 마지막 4글자만 보입니다.
- 공급자의 주소를 바꾸면, 저장된 키는 여러분이 변경을 승인할 때까지 새 주소로 보내지지 않습니다.
- 저장이 실패하면 키를 포함한 모든 것이 원래대로 돌아갑니다. 반만 저장되는 일은 없습니다.
- 잘못된 설정(모르는 공급자 종류, 이상한 주소, 음수 가격, 깨진 흐름)은 저장 전에 걸러지므로 앱은 언제나 깔끔하게 다시 시작됩니다.
- 프로젝트나 스킬이 바로가기 링크로 앱이 자기 폴더 밖의 파일을 읽거나 쓰게 만들 수 없습니다.
- 작업을 지우면 그 작업이 만든 브랜치만 지워집니다. 원래 있던 브랜치는 그대로 둡니다.
