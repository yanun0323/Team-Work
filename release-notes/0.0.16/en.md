## What's new

**Progress bars that tell the truth**
- On long steps, the bar used to rush to 90% and then sit there. It now moves at a steadier pace, so you can better tell how far along a step really is.

**Town view looks right**
- Busy animations (shouting, flying bills) no longer show through buildings standing in front of them.

**Safer with your keys and files**
- API keys and passwords in tool logs are hidden now. Only the last 4 characters show.
- If you change a provider's address, your saved key is not sent there until you approve the change.
- If saving a change fails, everything goes back to how it was, keys included. Nothing is left half-saved.
- Bad settings (unknown provider types, odd addresses, negative prices, broken flows) are caught before saving, so the app always starts up again cleanly.
- A project or skill can no longer use a shortcut link to make the app read or write files outside its own folder.
- Removing a task only deletes the branch that task made. Branches you already had are left alone.
