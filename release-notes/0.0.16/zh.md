## 新功能

**說實話的進度條**
- 步驟很長時，進度條以前會衝到 90% 然後停住。現在會用比較穩定的速度前進，比較看得出步驟實際做到哪裡。

**小鎮畫面正確了**
- 忙碌動畫（大喊、飛舞的鈔票）不會再穿過擋在前面的大樓。

**金鑰和檔案更安全**
- 工具記錄裡的 API 金鑰和密碼會被遮住，只顯示最後 4 個字元。
- 改了供應商的網址時，存好的金鑰要等你同意這個改動後，才會送到新網址。
- 儲存失敗時，所有東西都會回到原本的樣子，金鑰也是，不會只存一半。
- 錯誤的設定（不認得的供應商類型、奇怪的網址、負的價格、壞掉的流程）會在儲存前被擋下，App 一定能順利重新啟動。
- 專案或技能不能再用捷徑連結，讓 App 讀寫自己資料夾以外的檔案。
- 刪除任務時，只會刪掉那個任務建立的分支，你原本就有的分支不會動。
