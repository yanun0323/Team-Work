## 새로운 기능

**직원은 묻기 전에 설명합니다**
- 직원이 무엇을 생각하는지는 보이지 않으므로, 이제 먼저 찾은 것과 제안을 적습니다. 아무것도 쓰지 않고 '위에서 말했듯이'라고 하는 일은 없습니다.
- 작업 단계, 회사 채팅, 공항 채팅 어디서나 그렇습니다.

**편집하는 동안에도 코드에 색이**
- 파일 탐색기에서 코드 파일을 편집해도 읽을 때와 똑같이 보입니다: 어두운 배경에 색이 입혀진 코드.
- Markdown 파일은 여전히 일반 텍스트 상자에서 열립니다.

**파란 숫자는 정말로 여러분을 기다리는 것만 셉니다**
- 회사 이름표의 파란 숫자는 여러분의 답을 기다리는 채팅도 셉니다. 이미 열어 봤더라도요.
- 답하면 사라집니다.
