## 新機能

**社員は質問の前に説明します**
- 社員が何を考えているかは見えないので、まず見つけたことと提案を書くようになりました。何も書いていないのに「上で述べたとおり」と言うことはもうありません。
- タスクのステップ、会社のチャット、空港のチャットのどこでも同じです。

**編集中もコードはカラフル**
- ファイルブラウザでコードファイルを編集しても、読むときと同じ見た目です。暗い背景に色付きのコードです。
- Markdown ファイルはこれまでどおりプレーンテキストの欄で開きます。

**青い数字は本当にあなたを待っているものを数えます**
- 会社の名札の青い数字は、あなたの答えを待っているチャットも数えるようになりました。すでに開いていても数えます。
- 答えると消えます。
