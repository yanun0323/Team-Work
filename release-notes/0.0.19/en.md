## What's new

**Employees explain before they ask**
- You can't see what an employee is thinking, so they now write down what they found and what they suggest first. No more "as mentioned above" pointing at nothing.
- This works everywhere: task steps, company chats and airport chats.

**Code files stay colourful while you edit them**
- Editing a code file in the file browser now looks the same as reading it: dark background, coloured code.
- Markdown files still open in the plain text box.

**The blue badge counts what's really waiting on you**
- The blue number on a company's name tag now also counts chats waiting for your answer, even if you've already opened them.
- It goes away once you answer.
