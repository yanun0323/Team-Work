## What's new

**Choose where sources list their blueprints and flows**
A source can now set the order its blueprints and flows appear in. Sources that don't set one keep the order they had.

**See the tower's link version**
The tower shows its link version next to its title, so you can tell at a glance whether two computers can talk to each other.

**Clearer copy button for visiting employees**
The button for copying an employee from another island now shows a small plane.

## Fixes

- Visitor controls from the last release need both computers on the new version. An older computer now gets the usual "please update" prompt instead of connecting without showing up in your visitor list.
- Creating a task from a chat no longer makes a task that can't be started: if no owner was picked, you're asked to choose one.
- A chat no longer goes blank and jumps back to the top when new messages arrive quickly while older ones are loading.
- A source made for a newer version of Team Work no longer fails to load on an older one; settings it doesn't understand are simply skipped.
