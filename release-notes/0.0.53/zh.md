## 新功能

**全島共用的人力資源公司**
機場後面多了一棟圓頂建築。在那裡雇的員工是大家共用的：每間公司都能挑他們，他們會用那間公司的資料夾、規則和權限工作。你可以把員工從公司移到人力資源公司，或從人力資源公司移到公司。移動後會重新開始，保留名字、外觀和設定，但不保留記憶。鎮民現在會從人力資源公司的門進出，周圍的路也保持暢通。

**從另一台電腦複製員工**
看配對電腦的島時，員工詳細資料上的複製按鈕會把他複製到你自己的人力資源公司。你可以選只帶技能來源，或連技能檔案一起帶；如果你的電腦沒有他用的模型，會先請你挑一個。

**一鍵複製員工**
員工詳細資料上的複製按鈕，會打開一張已經填好員工藍圖、模型、思考等級和外觀的新進員工表單。名字後面加上「-1」，你按「新增」之前不會真的雇人。

**會議更像真的對話**
在會議裡，大家現在可以寫 @名字 把發言權交給別人。沒有點名時，輪到主持人。你隨時可以插話：你說的話會取代還在排隊的發言；提到被允許參與任務的員工，會把他拉進會議。對一場因上限而暫停的會議說話，會讓它重新開始。

**更順的小島、更快的對話清單**
小島畫起來省力很多，移動更順，尤其是人多的時候。長的對話清單也開得更快。

## 修正

- 合併失敗時，任務現在會說明原因（例如專案資料夾裡有會被合併蓋掉的未 commit 檔案），以及下一步該怎麼做。原因會顯示在回覆框上方、對話裡和合併那一列，「合併」按鈕也不能按兩次。
- 地圖上的標籤不會再顯示在蓋在地圖上的面板之上。
- 從另一台電腦複製員工時會保留思考等級；同一份複製再送一次也不會雇兩次，重新啟動後也一樣。
