## 新機能

**長い会話を適切なタイミングで要約**
会話が上限に近づくと、Team Work は推測だけに頼らず、モデルのプロバイダーに実際の長さを問い合わせるようになりました。早すぎも遅すぎもせず、必要なときに要約され、画面に表示される使用量も実際の計算と一致します。Anthropic、OpenAI、ほとんどのセルフホストサーバーで使えます。

**指示を短くしてトークンを節約**
返信ごとに送るツールとスキルの一覧が短くなり、毎回の返信が少し安くなりました。

## 修正

**黙って止まらなくなりました**
モデルが何も言わずにターンを終えた場合、Team Work はそこで止まらず、もう一度問い合わせます。
