## 새 기능

**긴 대화를 알맞은 때에 정리**
대화가 한도에 가까워지면 Team Work가 추정에만 의존하지 않고 모델 제공업체에 실제 길이를 물어봅니다. 너무 이르지도 늦지도 않게 필요할 때 정리되며, 화면에 보이는 사용량도 실제 계산과 같습니다. Anthropic, OpenAI 및 대부분의 자체 호스팅 서버에서 작동합니다.

**더 짧은 지시, 더 적은 토큰**
답변마다 보내는 도구와 스킬 목록이 짧아져 답변마다 조금씩 비용이 줄어듭니다.

## 수정

**조용히 멈추지 않음**
모델이 아무 말 없이 차례를 끝내면 Team Work가 거기서 멈추지 않고 한 번 더 요청합니다.
