## 新功能

**任务改由任务负责人主导**
新任务由它的任务负责人带领。你选的流程只是一开始的计划：负责人会把每一步连同指示交给员工、检查每个结果、回答员工的问题、召开会议，也能在工作进行中新增、跳过或改派步骤。它只会用你允许的人，需要更多人时会先问你。计划的每次变动都会在任务的对话里留下一行简短记录。你已有的任务照旧方式运行。

**更简单的任务面板**
由负责人主导的任务会以单栏打开，像一张工单：最上面是标题和负责人，步骤是一张张小便签，接着是对话。等你回答的问题会固定在看得到的地方，最下面的输入框是和负责人说话。每位员工说的话都会标出来自哪一步；暂停、继续、退回或回答时，也会显示有没有成功。

**只有你能调用的技能**
技能现在可以标成只属于你。员工不会自己拿去用，但你用 `$名称` 点名时照样有效。

**在任何地方缩放地图**
在地图上的名牌上滚动，现在也会缩放地图，和在其他地方滚动一样。

**“Base URL”和更多翻译好的标签**
API 地址字段现在叫“Base URL”。Prompt、API Key、Base URL 和 Context window 等标签，现在也有日文和韩文了。

## 修复

- 负责人主导的任务，在某一步的工作被退回、还没完成或根本没运行时，不会再结束或合并。
- 步骤连续失败三次后，负责人会停下来等你。
- 暂停、退回和停止现在都会确实生效，即使运行状态不确定也一样。
- 停下来的任务再继续时，会按现在的计划走，不会按以前的。
- 工作记录很长的任务加载更快。
