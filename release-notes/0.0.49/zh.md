## 新功能

**任務改由任務負責人主導**
新任務由它的任務負責人帶領。你選的流程只是一開始的計畫：負責人會把每一步連同指示交給員工、檢查每個結果、回答員工的問題、召開會議，也能在工作進行中新增、跳過或改派步驟。它只會用你允許的人，需要更多人時會先問你。計畫的每次變動都會在任務的對話裡留下一行簡短紀錄。你已經有的任務照舊方式執行。

**更簡單的任務面板**
由負責人主導的任務會以單欄打開，像一張工單：最上面是標題和負責人，步驟是一張張小便條，接著是對話。等你回答的問題會固定在看得到的地方，最下面的輸入框是和負責人說話。每位員工說的話都會標出來自哪一步；暫停、繼續、退回或回答時，也會顯示有沒有成功。

**只有你能叫用的技能**
技能現在可以標成只屬於你。員工不會自己拿去用，但你用 `$名稱` 點名時照樣有效。

**在任何地方縮放地圖**
在地圖上的名牌上滾動，現在也會縮放地圖，跟在其他地方滾動一樣。

**「Base URL」和更多翻譯好的標籤**
API 位址欄位現在叫「Base URL」。Prompt、API Key、Base URL 和 Context window 等標籤，現在也有日文和韓文了。

## 修正

- 負責人主導的任務，在某一步的工作被退件、還沒完成或根本沒執行時，不會再結束或合併。
- 步驟連續失敗三次後，負責人會停下來等你。
- 暫停、退回和停止現在都會確實生效，就算執行狀態不確定也一樣。
- 停下來的任務再繼續時，會照現在的計畫走，不會照以前的。
- 工作紀錄很長的任務載入更快。
