## 新機能

**タスクは責任者が進めます**
新しいタスクはタスク責任者が率います。選んだフローは最初の計画にすぎません。責任者は各ステップを指示付きで渡し、結果をすべて確認し、社員に答え、ミーティングを開き、作業の途中でステップを追加・スキップ・担当替えできます。あなたが許可した人の範囲で動き、もっと人が必要なときは先にあなたに聞きます。計画が変わるたびに、タスクの会話に短い一行が残ります。既存のタスクは以前のやり方で動き続けます。

**シンプルなタスクパネル**
責任者が進めるタスクは、チケットのような 1 列で開きます。上にタイトルと責任者、ステップは小さなメモとして並び、その下に会話があります。あなたの答えを待つ質問は見える場所に固定され、下の入力欄で責任者と話します。社員の発言にはどのステップから来たかが示され、一時停止、再開、差し戻し、回答がうまくいったかどうかも表示されます。

**あなただけが呼べるスキル**
スキルを自分専用にできるようになりました。社員が自分から使うことはありませんが、`$名前` で指名すればこれまでどおり使えます。

**どこでも地図をズーム**
地図上のラベルの上でスクロールしても、ほかの場所と同じように地図がズームします。

**「Base URL」と翻訳されたラベル**
API アドレスの欄は「Base URL」という名前になりました。Prompt、API Key、Base URL、Context window などのラベルが日本語と韓国語でも表示されます。

## 修正

- 責任者が進めるタスクは、あるステップの作業が却下された、まだ終わっていない、または一度も実行されていないときに、完了やマージをしなくなりました。
- ステップが 3 回続けて失敗すると、責任者は止まってあなたを待ちます。
- 一時停止、差し戻し、停止は、実行の状態がはっきりしないときでもきちんと反映されます。
- 止まったタスクを再開すると、以前の計画ではなく今の計画に従います。
- 作業ログが長いタスクも速く読み込めます。
