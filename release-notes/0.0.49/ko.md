## 새로운 기능

**작업을 이제 책임자가 이끕니다**
새 작업은 작업 책임자가 이끕니다. 고른 흐름은 처음의 계획일 뿐입니다: 책임자가 각 단계를 지시와 함께 나눠 주고, 모든 결과를 검토하고, 직원에게 답하고, 회의를 열며, 일하는 도중에 단계를 추가·건너뛰기·재배정할 수 있습니다. 여러분이 허락한 사람들 안에서만 움직이고, 사람이 더 필요하면 먼저 묻습니다. 계획이 바뀔 때마다 작업 대화에 짧은 한 줄이 남습니다. 이미 있는 작업은 예전 방식대로 돌아갑니다.

**더 단순한 작업 패널**
책임자가 이끄는 작업은 티켓처럼 한 열로 열립니다: 맨 위에 제목과 책임자, 단계는 작은 메모로, 그 아래에 대화가 있습니다. 여러분의 답을 기다리는 질문은 잘 보이는 곳에 고정되고, 아래 입력창은 책임자와 이야기합니다. 직원의 말에는 어느 단계에서 왔는지 표시되고, 일시 정지·재개·되돌려 보내기·답변이 잘 됐는지도 보입니다.

**여러분만 부를 수 있는 스킬**
스킬을 여러분 전용으로 표시할 수 있습니다. 직원이 스스로 쓰지는 않지만, `$이름`으로 지목하면 여전히 동작합니다.

**어디서나 지도 확대·축소**
지도 위 이름표 위에서 스크롤해도 다른 곳처럼 지도가 확대·축소됩니다.

**'Base URL'과 더 많이 번역된 이름표**
API 주소 칸 이름이 'Base URL'이 되었습니다. Prompt, API Key, Base URL, Context window 같은 이름표가 일본어와 한국어로도 보입니다.

## 수정

- 책임자가 이끄는 작업은 어떤 단계의 일이 거절됐거나, 아직 끝나지 않았거나, 한 번도 실행되지 않았으면 끝나거나 병합되지 않습니다.
- 단계가 세 번 연속 실패하면 책임자가 멈추고 여러분을 기다립니다.
- 일시 정지, 되돌려 보내기, 중지가 실행 상태가 불확실할 때도 제대로 반영됩니다.
- 멈춘 작업을 다시 진행하면 예전 계획이 아니라 지금 계획을 따릅니다.
- 작업 기록이 긴 작업도 더 빨리 불러옵니다.
