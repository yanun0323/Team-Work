## 새로운 기능

**Git repo에서 스킬 추가가 더 안전해졌습니다**
- 도우미가 써 본 적 없는 Git repo에서 블루프린트에 스킬을 추가하려 하면, 먼저 그 repo를 열어 제대로 되는지 확인합니다.
- repo를 열 수 없거나 스킬이 없으면, 나중에 여러분이 알게 되는 대신 도우미가 바로 거절당합니다.
- 승인 카드에 새 repo가 '새 소스'로, 쓸 브랜치와 버전과 함께 보이므로 무엇에 동의하는지 정확히 알 수 있습니다.
- 여러분이 승인하기 전에 누군가 같은 repo를 다른 버전으로 추가하면, 몰래 섞지 않고 변경이 멈춥니다.
