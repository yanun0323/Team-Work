## 新機能

**Git の repo からスキルを追加するのがより安全に**
- アシスタントが、まだ使ったことのない Git の repo からブループリントにスキルを加えようとするとき、まずその repo を開いて使えるか確かめます。
- repo を開けない、またはスキルが入っていない場合は、あとであなたが気づくのではなく、その場でアシスタントに断られます。
- 承認カードには新しい repo が「新しいソース」として、使うブランチとバージョンと一緒に表示されるので、何に同意するのかがはっきりわかります。
- あなたが承認する前に、誰かが同じ repo を別のバージョンで追加した場合、黙って混ぜずに変更が止まります。
