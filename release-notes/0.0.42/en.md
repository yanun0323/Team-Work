## What's new

**Sources update sooner**
The app now looks for new versions of your skill and blueprint sources every hour instead of every 6 hours, so new skills and blueprints show up the same day. You can still press the refresh button on a source to check right away.

**Your flow list stays tidy**
When an employee sets up a task with a one-off flow, that flow now stays with the task alone. It no longer gets saved into your flow list, so the list only holds the flows you actually keep.
