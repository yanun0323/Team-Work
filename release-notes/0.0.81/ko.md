## 새 기능

**이미지 크기 지정**
직원이 그림을 그릴 때 가로로 긴 2048×1152처럼 정확한 크기를 지정할 수 있습니다. ChatGPT 구독은 최대 3840×2160이고, 직접 운영하는 이미지 생성 서버는 서버가 최대 크기를 정합니다. 지정하지 않으면 원래 크기로 그립니다.

## 수정

**자체 이미지 생성 서버에서 큰 그림도 끝까지 완성**
자체 이미지 생성 서버로 큰 그림을 그리면 2분이 넘거나 파일이 너무 커서 실패하곤 했습니다. 이제 Team Work가 최대 15분까지 기다리고 훨씬 큰 파일도 받습니다.

**아주 큰 그림도 대화에 표시**
대화에 첨부할 수 없을 만큼 큰 그림은 이제 아예 안 보이는 대신 작은 미리보기로 표시됩니다. 원본 그림은 폴더에 그대로 저장됩니다.
