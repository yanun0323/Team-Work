## 新機能

**画像サイズを指定できるように**
社員が画像を描くとき、横長の 2048×1152 のように正確なサイズを指定できるようになりました。ChatGPT サブスクリプションでは最大 3840×2160、自前の画像生成サーバーではサーバーが上限を決めます。指定しなければ、これまでどおりのサイズになります。

## 修正

**自前の画像生成サーバーで大きな画像が最後まで描けるように**
自前の画像生成サーバーで大きな画像を描くと、2 分を超えたりファイルが大きすぎたりして失敗していました。Team Work は最大 15 分待ち、はるかに大きなファイルも受け取れるようになりました。

**とても大きな画像も会話に表示**
会話に添付できないほど大きな画像は、表示されないのではなく、小さなプレビューで表示されるようになりました。元の画像はフォルダーにそのまま保存されます。
