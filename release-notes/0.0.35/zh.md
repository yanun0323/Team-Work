## 新功能

**員工藍圖和任務藍圖改從同一個地方來**
13 個起始員工藍圖（通才、前端工程師等）和 4 個起始任務藍圖，現在放在它們自己的 GitHub repo：[Team-Work-Source](https://github.com/yanun0323/Team-Work-Source)。App 第一次打開時會下載，之後自己保持最新，所以它們不必等 App 出新版就能變得更好。第一次下載後離線也能用。它們也有英文、中文、日文和韓文版本。

**升級前請注意**
還在用舊內建員工藍圖的員工，畫面上照常運作，但會標示「員工藍圖已不存在」。再交工作給他們之前，請打開員工、重新選一個員工藍圖並儲存。沒做的話，任務輪到他們時會停下來請你處理。

**圖片更大，紀錄更小**
附加或貼上的圖片現在最大可以到 25MB，超過 3.75MB 的會自動縮小。圖片另外存成檔案，不再放在對話紀錄裡，長對話載入更輕。舊對話會在第一次啟動 App 時搬過去，不會刪掉任何東西。

**你離開時鏡頭會跟著某個人**
一段時間不碰地圖，鏡頭會挑島上的一個人跟著走。碰任何東西就會停下。可以在設定裡選等多久，或關掉。也可以讓它跟著辦公室裡的員工。

**大家不再撞在一起**
島上和辦公室裡的人現在會互相讓路：在窄的地方讓開、在門口等，不會穿過別人。島上的人也會停下來看飛機飛過。

**更熱鬧的機場**
停著的飛機會有地勤來好好服務：等待時卡車和設備會開過來。飛機本身也更有細節。

**小改動**
- 新的 App 圖示。
- 設定裡的分組可以摺起來，App 會記住你哪些是打開的。
- 往下捲詳細頁面時，按鈕會留在上面，不會讓文字滑到它們下面。
- 視窗不在焦點時，地圖更省電。
