## 新功能

**员工蓝图和任务蓝图改从同一个地方来**
13 个初始员工蓝图（通才、前端工程师等）和 4 个初始任务蓝图，现在放在它们自己的 GitHub repo：[Team-Work-Source](https://github.com/yanun0323/Team-Work-Source)。App 第一次打开时会下载，之后自己保持最新，所以它们不必等 App 出新版就能变得更好。第一次下载后离线也能用。它们也有英文、中文、日文和韩文版本。

**升级前请注意**
还在用旧内置员工蓝图的员工，画面上照常运行，但会标注“员工蓝图已不存在”。再交工作给他们之前，请打开员工、重新选一个员工蓝图并保存。没做的话，任务轮到他们时会停下来请你处理。

**图片更大，记录更小**
附加或粘贴的图片现在最大可以到 25MB，超过 3.75MB 的会自动缩小。图片单独存成文件，不再放在对话记录里，长对话加载更轻。旧对话会在第一次启动 App 时迁移过去，不会删除任何东西。

**你离开时镜头会跟着某个人**
一段时间不碰地图，镜头会挑岛上的一个人跟着走。碰任何东西就会停下。可以在设置里选等多久，或关掉。也可以让它跟着办公室里的员工。

**大家不再撞在一起**
岛上和办公室里的人现在会互相让路：在窄的地方让开、在门口等，不会穿过别人。岛上的人也会停下来看飞机飞过。

**更热闹的机场**
停着的飞机会有地勤来好好服务：等待时卡车和设备会开过来。飞机本身也更有细节。

**小改动**
- 新的 App 图标。
- 设置里的分组可以折叠，App 会记住你哪些是打开的。
- 往下滚动详情页面时，按钮会留在上面，不会让文字滑到它们下面。
- 窗口不在焦点时，地图更省电。
