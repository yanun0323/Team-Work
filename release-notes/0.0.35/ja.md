## 新機能

**ブループリントとワークフローは 1 か所から**
最初から入っている 13 のブループリント（ジェネラリスト、フロントエンドエンジニアなど）と 4 つのワークフローは、専用の GitHub repo [Team-Work-Source](https://github.com/yanun0323/Team-Work-Source) に移りました。アプリは初回起動時にダウンロードし、その後は自動で最新に保つので、アプリの新バージョンを待たずに良くなっていきます。最初のダウンロードのあとはオフラインでも使えます。英語、中国語、日本語、韓国語に対応しています。

**アップグレードする方へ**
古い組み込みブループリントのままの社員も画面上では動きますが、「ブループリントがもうありません」と表示されます。仕事を渡す前に、社員を開いてブループリントを選び直し、保存してください。しなかった場合、その社員に回ってきたタスクは止まって、あなたに対応を求めます。

**画像は大きく、履歴は小さく**
添付や貼り付けの画像は 25MB まで使えるようになりました。3.75MB を超えるものは自動で縮小します。画像はチャット履歴の中ではなく別のファイルとして保存されるので、長いチャットも軽く読み込めます。古いチャットはアプリを初めて起動したときに移されます。何も削除されません。

**離れている間、カメラが誰かを追いかけます**
しばらく地図を触らずにいると、カメラが島の誰かを選んで追いかけます。何かに触ると止まります。待ち時間やオフは設定で選べます。オフィスの中の社員を追いかけるようにもできます。

**人どうしがぶつからなくなりました**
島とオフィスの人たちは互いに道をゆずるようになりました。狭いところでは脇によけ、ドアの前で待ち、人をすり抜けません。島の人たちは飛行機が飛ぶのを立ち止まって眺めることもあります。

**にぎやかな空港**
駐機中の飛行機に地上スタッフがちゃんとやって来ます。待っている間にトラックや機材が横付けされます。飛行機自体も細かく作り込みました。

**細かな変更**
- 新しいアプリアイコン。
- 設定のグループを折りたためるようになり、開いておいたグループをアプリが覚えます。
- 詳細ページを下にスクロールしても、ボタンが上に残り、文字がその下に潜り込みません。
- ウインドウがフォーカスされていないとき、地図の消費電力が減ります。
