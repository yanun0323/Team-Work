## 새로운 기능

**블루프린트와 워크플로가 이제 한곳에서 옵니다**
처음부터 있던 블루프린트 13개(제너럴리스트, 프런트엔드 엔지니어 등)와 워크플로 4개가 이제 전용 GitHub repo인 [Team-Work-Source](https://github.com/yanun0323/Team-Work-Source)에 있습니다. 앱은 처음 열 때 이것들을 내려받고 스스로 최신 상태로 유지하므로, 앱의 새 버전을 기다리지 않고도 더 좋아질 수 있습니다. 처음 내려받은 뒤에는 오프라인에서도 동작합니다. 영어, 중국어, 일본어, 한국어로도 제공됩니다.

**업그레이드한다면 알아 두세요**
예전 기본 블루프린트로 설정된 직원도 화면에서는 계속 동작하지만 '블루프린트가 더 이상 없음'으로 표시됩니다. 일을 더 맡기기 전에 직원을 열어 블루프린트를 다시 고르고 저장하세요. 건너뛰면 그 직원에게 차례가 온 작업이 멈추고 이 일을 해 달라고 요청합니다.

**이미지는 더 크게, 기록은 더 작게**
첨부하거나 붙여 넣는 이미지는 이제 25MB까지 됩니다. 3.75MB가 넘으면 알아서 줄입니다. 이미지는 채팅 기록 안이 아니라 별도 파일로 저장되므로 긴 채팅도 가볍게 열립니다. 예전 채팅은 앱을 처음 시작할 때 옮겨지며, 아무것도 지워지지 않습니다.

**잠시 자리를 비우면 카메라가 누군가를 따라갑니다**
지도를 잠시 그대로 두면 카메라가 섬에서 한 사람을 골라 따라다닙니다. 무엇이든 건드리면 멈춥니다. 기다리는 시간이나 끄기는 설정에서 고를 수 있습니다. 사무실 안의 직원을 따라가게 할 수도 있습니다.

**사람들이 서로 부딪히지 않습니다**
섬과 사무실의 사람들이 서로 길을 비켜 줍니다. 좁은 곳에서는 옆으로 비키고, 문 앞에서 기다리며, 누구도 통과해 지나가지 않습니다. 섬 사람들은 비행기가 지나가는 것을 멈춰 서서 보기도 합니다.

**더 활기찬 공항**
세워 둔 비행기에 지상 직원이 제대로 찾아옵니다. 기다리는 동안 트럭과 장비가 다가옵니다. 비행기 자체도 더 자세해졌습니다.

**작은 변경**
- 새 앱 아이콘.
- 설정의 그룹을 접을 수 있고, 어떤 그룹을 펼쳐 두었는지 앱이 기억합니다.
- 상세 페이지를 아래로 스크롤해도 버튼이 위에 남아 글자가 그 아래로 미끄러지지 않습니다.
- 창이 포커스되지 않았을 때 지도가 전력을 덜 씁니다.
