## 新功能

**新 Mac 上檢查 Git**
- Mac 還沒有 Git 時，App 會告訴你，並暫停到裝好為止。按「安裝」會打開 Apple 自己的安裝程式，裝好後 App 會自己繼續。
- 以前沒有 Git 的 Mac 可能會突然跳出系統安裝視窗，或任務直接失敗。

**程式碼有顏色了**
- 程式檔，以及對話和筆記裡的程式碼區塊，會依語言上色；程式碼區塊也有複製按鈕。
- 筆記可以顯示 HTML 和專案裡的圖片。

**檔案瀏覽更好用**
- 點檔案會在自己的一張單子上打開。編輯在另一張單子上做；還沒儲存的草稿會留著，並顯示紅點。
- 被 Git 忽略的檔案（例如建置產物）在檔案樹和 `#` 檔案選單裡會變成灰色。

**員工直接做事**
- 在對話裡，員工會當場把工作做完，不會一直叫你去建任務。
- 需要你回答時，會給可以點的選項，不必讓你打字。

**小改動**
- 可以關掉大樓的忙碌動畫。
- `make dev` 的資料改放在 `~/.team-work-dev`，可以和安裝好的 App 同時執行。
