## 新功能

**新 Mac 上检查 Git**
- Mac 还没有 Git 时，App 会告诉你，并暂停到装好为止。点“安装”会打开 Apple 自己的安装程序，装好后 App 会自己继续。
- 以前没有 Git 的 Mac 可能会突然弹出系统安装窗口，或任务直接失败。

**代码有颜色了**
- 代码文件，以及对话和笔记里的代码块，会按语言上色；代码块也有复制按钮。
- 笔记可以显示 HTML 和项目里的图片。

**文件浏览更好用**
- 点文件会在单独的一张页面上打开。编辑在另一张页面上进行；还没保存的草稿会保留，并显示红点。
- 被 Git 忽略的文件（例如构建产物）在文件树和 `#` 文件菜单里会变成灰色。

**员工直接干活**
- 在对话里，员工会当场把工作做完，不会一直让你去建任务。
- 需要你回答时，会给可以点的选项，不必让你输入。

**小改动**
- 可以关掉大楼的忙碌动画。
- `make dev` 的数据改放在 `~/.team-work-dev`，可以和安装好的 App 同时运行。
