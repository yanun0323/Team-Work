## 新機能

**新しい Mac で Git を確認**
- Mac にまだ Git がない場合、アプリがそれを伝え、インストールされるまで一時停止します。「インストール」を押すと Apple のインストーラが開き、終わるとアプリは自分で再開します。
- 以前は Git のない Mac で、突然システムのインストール画面が出たり、タスクがそのまま失敗したりしていました。

**コードに色が付きます**
- コードファイルや、チャットとメモのコードブロックが言語ごとに色分けされ、コードブロックにはコピーボタンが付きました。
- メモで HTML やプロジェクト内の画像を表示できます。

**ファイルタブが使いやすく**
- ファイルをクリックすると、専用のシートで開きます。編集は別のシートで行い、保存していない下書きは残って赤い点が付きます。
- Git が無視するファイル（ビルドの出力など）は、ファイルツリーと `#` のファイルメニューでグレー表示になります。

**社員はとにかく作業する**
- チャットでは、タスクを作るよう促すのではなく、社員がその場で作業します。
- あなたの答えが必要なときは、入力させずにクリックできる選択肢で聞きます。

**その他**
- ビルの忙しいアニメーションをオフにできます。
- `make dev` のデータは `~/.team-work-dev` に置かれるようになり、インストール済みのアプリと並べて動かせます。
