## What's new

**Git check on a fresh Mac**
- If your Mac doesn't have Git yet, the app now tells you and pauses until it's installed. Press Install and Apple's own installer opens. The app picks up again by itself once it's done.
- Before, a Mac without Git could pop up a system install window out of nowhere, or tasks just failed.

**Colored code**
- Code files and code blocks in chats and notes are now colored by language, and code blocks have a copy button.
- Notes can show HTML and pictures from your project.

**Files tab, easier to use**
- Click a file to open it on its own sheet. Edit in a separate sheet; drafts you haven't saved stay put and show a red dot.
- Files Git ignores (like build output) are greyed out, in the file tree and in the `#` file menu.

**Employees just do the work**
- In chats, employees now do the work right there instead of pushing you to make a task.
- When they need your answer, they ask with clickable choices instead of making you type.

**Smaller things**
- You can turn off the busy animation on buildings.
- `make dev` now keeps its data in `~/.team-work-dev`, so it can run next to the installed app.
