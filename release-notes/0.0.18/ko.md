## 새로운 기능

**새 Mac에서 Git 확인**
- Mac에 아직 Git이 없으면 앱이 알려 주고 설치될 때까지 멈춥니다. '설치'를 누르면 Apple의 설치 프로그램이 열리고, 끝나면 앱이 스스로 다시 시작합니다.
- 전에는 Git이 없는 Mac에서 갑자기 시스템 설치 창이 뜨거나 작업이 그냥 실패했습니다.

**색이 입혀진 코드**
- 코드 파일과 채팅·메모의 코드 블록이 언어별로 색이 입혀지고, 코드 블록에 복사 버튼이 생겼습니다.
- 메모에서 HTML과 프로젝트의 이미지를 보여 줄 수 있습니다.

**더 쓰기 쉬운 파일 탭**
- 파일을 클릭하면 별도의 시트에서 열립니다. 편집은 다른 시트에서 하며, 저장하지 않은 초안은 남아 있고 빨간 점이 표시됩니다.
- Git이 무시하는 파일(빌드 결과물 등)은 파일 트리와 `#` 파일 메뉴에서 회색으로 보입니다.

**직원은 그냥 일합니다**
- 채팅에서 직원이 작업을 만들라고 재촉하지 않고 그 자리에서 일을 합니다.
- 여러분의 답이 필요하면 입력하게 하지 않고 클릭할 수 있는 선택지로 묻습니다.

**그 밖의 변경**
- 건물의 바쁜 애니메이션을 끌 수 있습니다.
- `make dev`는 이제 데이터를 `~/.team-work-dev`에 두므로 설치된 앱과 나란히 실행할 수 있습니다.
