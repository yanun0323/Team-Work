## 새 기능

**채팅에서 그림이 보여요**
직원이 그림을 열어 볼 때 이제 채팅에도 그 그림이 표시됩니다. 하나를 열고 왼쪽·오른쪽 화살표 키로 채팅 속 그림을 넘겨 볼 수 있습니다.

**새 작업이 로컬 파일을 가지고 시작해요**
새 작업은 이제 git이 추적하지 않는 프로젝트 파일(설정 파일, 로컬 설정 등)을 가진 채로 시작해서, 직원이 바로 실행할 수 있습니다. 다시 만들 수 있는 큰 폴더와 프로젝트를 다시 가리키는 링크는 가져가지 않습니다.

**직접 운영하는 서버의 긴 답변이 끝까지 와요**
직접 운영하는 서버의 모델이 길이 제한 때문에 답변을 중간에 멈추면, Team Work가 멈춘 곳부터 이어서 쓰도록 요청해 잘린 채로 남지 않습니다.

**서버 모델의 길이를 항상 최신으로**
서버가 같은 이름으로 다른 모델로 바꿔도, Team Work가 다음 답변 전에 새 컨텍스트 길이를 읽어 옵니다.

**채팅을 정리하는 중임을 보여 줘요**
Team Work가 채팅의 예전 메시지를 요약하는 동안 채팅에 정리 중이라고 표시되어, 멈춘 것처럼 보이지 않습니다.

## 수정

**긴 채팅이 실패하지 않고 요약돼요**
읽을 수 있는 양이 적은 모델에 넘겨진 채팅이나, llama.cpp, LM Studio, Gemini, Mistral 같은 서버가 다른 표현으로 "너무 길다"고 알려도 답변이 실패하지 않고, 채팅을 요약한 뒤 이어 갑니다.

**지도가 먼 시점으로 돌아가요**
카메라가 멀어지며 돌아가는 도중 건물을 빠르게 다시 클릭하면 중간에서 멈췄습니다. 이제 끝까지 먼 시점으로 돌아갑니다.

**버전 설명이 읽기 쉬워졌어요**
버전 설명에서 각 변경 사항이 또렷하게 나뉘고, 제목이 본문 바로 위에 붙도록 바뀌었습니다.
