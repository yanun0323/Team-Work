## 新功能

**對話裡看得到圖片**
員工打開圖片來看時，對話裡現在也會顯示那張圖。點開一張後，可以用左右方向鍵切換對話裡的圖片。

**新任務帶著你的本機檔案開始**
新任務現在一開始就有專案裡 git 不追蹤的檔案，例如設定檔和本機設定，員工可以直接跑起來。可以重新產生的大資料夾，以及指回專案的連結不會帶過去。

**自架伺服器的長回覆會寫完**
自己伺服器上的模型因為長度上限把回覆停在一半時，Team Work 現在會請它從停下的地方接著寫，不再留下被截斷的回覆。

**自架伺服器的模型長度隨時更新**
如果你的伺服器用同一個名字換了另一個模型，Team Work 會在下一次回覆前讀到新的上下文長度。

**整理對話時會顯示出來**
Team Work 整理對話裡較早的訊息時，對話會顯示正在整理，不會看起來像卡住。

## 修正

**長對話會整理，不再失敗**
對話交給讀得比較少的模型，或 llama.cpp、LM Studio、Gemini、Mistral 等伺服器用不同說法回報太長時，回覆不再失敗，而是先整理對話再繼續。

**地圖會回到遠景**
鏡頭往外拉回時很快再點一次建築，畫面會停在半路。現在會完整回到遠景。

**版本說明更好讀**
版本說明裡每一項改動現在分得更清楚，標題緊貼在內文上方。
