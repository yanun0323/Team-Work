## 新機能

**チャットで画像が見える**
社員が画像を開いて見たとき、その画像がチャットにも表示されるようになりました。1枚開いたら、左右の矢印キーでチャット内の画像を切り替えられます。

**新しいタスクにローカルのファイルを持ち込み**
新しいタスクは、git が追跡しないプロジェクトのファイル（設定ファイルやローカル設定など）を持った状態で始まるので、社員はすぐに動かせます。作り直せる大きなフォルダや、プロジェクトを指し返すリンクは持ち込みません。

**自前サーバーの長い返答が最後まで届く**
自前サーバーのモデルが長さの上限で返答を途中で止めたとき、Team Work が止まったところから続きを書くよう頼むようになり、途切れたままになりません。

**自前サーバーのモデルの長さを常に最新に**
サーバーが同じ名前のまま別のモデルに切り替えても、Team Work は次の返答の前に新しいコンテキスト長を読み取ります。

**チャットを整理中であることを表示**
Team Work がチャットの古いメッセージをまとめている間、チャットにその旨が表示され、止まっているように見えなくなりました。

## 修正

**長いチャットは失敗せずにまとめられる**
読める量が少ないモデルに渡されたチャットや、llama.cpp、LM Studio、Gemini、Mistral などのサーバーが別の言い方で「長すぎる」と返したときも、返答が失敗せず、チャットをまとめてから続けます。

**マップが遠景に戻る**
カメラが引いて戻る途中で建物をすばやくもう一度クリックすると、途中の位置で止まっていました。今は遠景まで戻ります。

**バージョンの説明が読みやすく**
バージョンの説明で各変更がはっきり分かれ、見出しが本文のすぐ上に来るようになりました。
