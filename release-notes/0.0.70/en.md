## What's new

**Pictures in the chat**
When an employee opens a picture to look at it, you now see that picture in the chat too. Open one and use the left and right arrow keys to step through the chat's pictures.

**New tasks start with your local files**
A new task now begins with the files git leaves out of your project, such as settings and local config, so employees can run things right away. Big rebuildable folders and anything linked back into the project are left behind.

**Long replies from your own server finish**
When a model on your own server stops a reply because it hit its length limit, Team Work now asks it to carry on from where it stopped, instead of leaving the reply cut off.

**Your server's model length stays current**
If your own server switches to another model under the same name, Team Work notices its new context length before the next reply.

**Shows when a chat is being tidied**
While Team Work sums up a chat's earlier messages, the chat now says so, instead of looking stuck.

## Fixes

**Long chats are summed up instead of failing**
A chat handed to a model that reads less, or an error worded differently by servers such as llama.cpp, LM Studio, Gemini or Mistral, no longer makes the reply fail. The chat is summed up and the reply goes on.

**The map goes back to the far view**
Clicking a building again quickly while the camera was flying back out left the view half-way. It now returns all the way.

**Version notes are easier to read**
Each change in the version notes now stands apart clearly, with its title close over its text.
