## 新功能

**对话里看得到图片**
员工打开图片来看时，对话里现在也会显示那张图。点开一张后，可以用左右方向键切换对话里的图片。

**新任务带着你的本机文件开始**
新任务现在一开始就有项目里 git 不追踪的文件，例如配置文件和本机设置，员工可以直接跑起来。可以重新生成的大文件夹，以及指回项目的链接不会带过去。

**自建服务器的长回复会写完**
自己服务器上的模型因为长度上限把回复停在一半时，Team Work 现在会请它从停下的地方接着写，不再留下被截断的回复。

**自建服务器的模型长度随时更新**
如果你的服务器用同一个名字换了另一个模型，Team Work 会在下一次回复前读到新的上下文长度。

**整理对话时会显示出来**
Team Work 整理对话里较早的消息时，对话会显示正在整理，不会看起来像卡住。

## 修正

**长对话会整理，不再失败**
对话交给读得比较少的模型，或 llama.cpp、LM Studio、Gemini、Mistral 等服务器用不同说法报告太长时，回复不再失败，而是先整理对话再继续。

**地图会回到远景**
镜头往外拉回时很快再点一次建筑，画面会停在半路。现在会完整回到远景。

**版本说明更好读**
版本说明里每一项改动现在分得更清楚，标题紧贴在正文上方。
