## What's new

**Three more languages**
Team Work now speaks Simplified Chinese, Japanese and Korean, on top of Traditional Chinese and English. Pick one in Settings. Menus, help, built-in roles and your employees' replies all switch with it.

**Sources can bring roles and workflows**
A source used to bring only skills. Now it can also bring employee roles and task workflows. They show up in their own group in your lists. You can't edit them, but you can make a copy and change that. If an update removes a role someone is still using, that employee keeps their current settings.

**Fewer, clearer built-in roles**
Some roles that overlapped are now one role: Security joins Code Reviewer, Data Analyst joins Researcher, Marketing joins Writer, and Project Manager joins Technical Planner. Product Owner is now Product Planner. Employees using a removed role move to the one that took over.

**Buildings grow in a new way**
- More employees make a building wider.
- A bigger project makes it taller.
- More finished tasks add decorations: a sign, flags, a billboard, neon lights, and finally an LED screen.

**Questions work more like you'd expect**
When an employee asks you to choose, clicking an option is your answer. If you type something else, they treat it as a new message and deal with that first, so they don't keep asking the same question. If they need you to type something, like a name or a key, they just ask in their reply.

## Fixes

- Claude no longer gets stuck when a chat has big images. Large images are shrunk before they're sent. If one is still too big, you get a clear message telling you what to do.
- The file browser no longer lists git's own hidden `.git` folder as if it were part of your project.
