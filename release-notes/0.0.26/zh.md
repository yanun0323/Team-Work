## 新功能

**多了三種語言**
Team Work 除了繁體中文和英文，現在也會簡體中文、日文和韓文。在設定裡選一種，選單、說明、內建角色和員工的回覆都會一起換。

**來源可以帶來角色和任務藍圖**
來源以前只能帶來技能，現在也能帶來員工角色和任務藍圖。它們在清單裡有自己的一組。不能直接編輯，但可以複製一份再改。如果更新拿掉了某個還有人在用的角色，那位員工會保留目前的設定。

**內建角色更少、更清楚**
一些重疊的角色合併了：資安併入程式碼審查、資料分析師併入研究員、行銷併入寫手、專案經理併入技術規劃師。產品負責人改名為產品規劃師。用到被拿掉角色的員工，會換到接手的那個角色。

**大樓用新的方式長大**
- 員工越多，大樓越寬。
- 專案越大，大樓越高。
- 完成的任務越多，裝飾越多：招牌、旗子、看板、霓虹燈，最後是 LED 螢幕。

**問題的運作更符合直覺**
員工請你選擇時，點選項就是你的回答。如果你打了別的內容，他們會把它當成新訊息先處理，不會一直問同一個問題。需要你打字（例如名稱或金鑰）時，他們會直接在回覆裡問。

## 修正

- 對話裡有大圖片時，Claude 不會再卡住。大圖片會先縮小再送出；如果還是太大，會清楚告訴你該怎麼做。
- 檔案瀏覽不會再把 git 自己的隱藏資料夾 `.git` 當成專案的一部分列出來。
