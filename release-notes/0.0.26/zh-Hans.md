## 新功能

**多了三种语言**
Team Work 除了繁体中文和英文，现在也会简体中文、日文和韩文。在设置里选一种，菜单、说明、内置角色和员工的回复都会一起切换。

**来源可以带来角色和任务蓝图**
来源以前只能带来技能，现在也能带来员工角色和任务蓝图。它们在列表里有自己的一组。不能直接编辑，但可以复制一份再改。如果更新去掉了某个还有人在用的角色，那位员工会保留当前的设置。

**内置角色更少、更清楚**
一些重叠的角色合并了：安全并入代码审查、数据分析师并入研究员、市场营销并入写手、项目经理并入技术规划师。产品负责人改名为产品规划师。用到被去掉角色的员工，会换到接手的那个角色。

**大楼用新的方式长大**
- 员工越多，大楼越宽。
- 项目越大，大楼越高。
- 完成的任务越多，装饰越多：招牌、旗子、广告牌、霓虹灯，最后是 LED 屏幕。

**提问的方式更符合直觉**
员工请你选择时，点选项就是你的回答。如果你输入了别的内容，他们会把它当成新消息先处理，不会一直问同一个问题。需要你输入（例如名称或密钥）时，他们会直接在回复里问。

## 修复

- 对话里有大图片时，Claude 不会再卡住。大图片会先缩小再发送；如果还是太大，会清楚告诉你该怎么做。
- 文件浏览不会再把 git 自己的隐藏文件夹 `.git` 当成项目的一部分列出来。
