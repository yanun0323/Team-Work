## 새로운 기능

**언어 세 개 추가**
Team Work가 이제 번체 중국어와 영어에 더해 간체 중국어, 일본어, 한국어를 지원합니다. 설정에서 고르면 메뉴, 도움말, 기본 역할, 직원의 답변이 모두 함께 바뀝니다.

**소스가 역할과 워크플로도 가져옵니다**
소스는 예전에 스킬만 가져왔지만, 이제 직원 역할과 작업 워크플로도 가져올 수 있습니다. 목록에서는 따로 묶여 보입니다. 직접 편집할 수는 없지만 복사본을 만들어 고칠 수 있습니다. 누군가 쓰고 있는 역할이 업데이트로 사라져도 그 직원은 지금 설정을 유지합니다.

**더 적고 분명한 기본 역할**
겹치던 역할을 하나로 합쳤습니다: 보안은 코드 리뷰어로, 데이터 분석가는 리서처로, 마케팅은 작가로, 프로젝트 매니저는 기술 기획자로 들어갔습니다. 프로덕트 오너는 프로덕트 기획자가 되었습니다. 없어진 역할을 쓰던 직원은 이어받은 역할로 옮겨 갑니다.

**건물이 새로운 방식으로 자랍니다**
- 직원이 많을수록 건물이 넓어집니다.
- 프로젝트가 클수록 건물이 높아집니다.
- 끝낸 작업이 많을수록 장식이 늘어납니다: 간판, 깃발, 광고판, 네온, 마지막으로 LED 화면.

**질문이 더 자연스럽게 동작합니다**
직원이 고르라고 할 때 선택지를 클릭하면 그것이 답입니다. 다른 내용을 입력하면 새 메시지로 보고 먼저 처리하므로 같은 질문을 되풀이하지 않습니다. 이름이나 키처럼 입력해야 할 것이 있으면 답변 안에서 그냥 물어봅니다.

## 수정

- 파일 탐색기가 git 자체의 숨김 폴더 `.git`을 프로젝트의 일부처럼 보여 주지 않습니다.
