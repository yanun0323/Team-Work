## 新機能

**3 つの言語を追加**
Team Work は繁体字中国語と英語に加えて、簡体字中国語、日本語、韓国語でも使えるようになりました。設定で選ぶと、メニュー、ヘルプ、組み込みの役割、社員の返信がすべて切り替わります。

**ソースが役割とワークフローも提供**
ソースはこれまでスキルだけでしたが、社員の役割とタスクのワークフローも提供できるようになりました。一覧では専用のグループに表示されます。直接は編集できませんが、コピーを作って変えられます。誰かが使っている役割がアップデートで消えても、その社員は今の設定を保ちます。

**組み込みの役割を少なく、わかりやすく**
重なっていた役割をまとめました。セキュリティはコードレビュアーに、データアナリストはリサーチャーに、マーケティングはライターに、プロジェクトマネージャーはテクニカルプランナーに統合しました。プロダクトオーナーはプロダクトプランナーになりました。消えた役割を使っていた社員は、引き継いだ役割に移ります。

**ビルの育ち方が新しく**
- 社員が増えるとビルが広くなります。
- プロジェクトが大きくなるとビルが高くなります。
- 完了したタスクが増えると飾りが増えます：看板、旗、広告板、ネオン、そして最後は LED スクリーン。

**質問がもっと自然に**
社員があなたに選んでもらうとき、選択肢をクリックすればそれが答えです。ほかのことを入力すると、それを新しいメッセージとして先に扱うので、同じ質問を繰り返しません。名前やキーなど入力してほしいときは、返信の中でそのまま聞きます。
