- **更新提示**：App 启动时会检查有没有新版本。有的话，机场上会出现一个小红点。
- **忙碌的大楼**：公司的人在工作时，大楼会轻轻晃动，一眼就看得出谁在忙。可以在设置里关掉。
- **项目自己的技能**：项目文件夹里如果有自己的技能，那家公司的每个人都能用。同名时优先用项目的，不用员工蓝图的。
- **技能开关**：可以选择要不要用你给 Codex 和 Claude 设置的技能。
- **机场对话可以指定任何文件**：在机场对话里输入 `#`，就能浏览主目录并指定一个文件。
- **登录提醒**：Claude 或 ChatGPT 订阅被退出登录时，App 会告诉你。
- **修复**：更新时会下载正确的版本。
