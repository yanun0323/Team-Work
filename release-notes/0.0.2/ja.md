- **アップデートのお知らせ**：起動時に新しいバージョンがあるか確認します。あれば空港に小さな赤い点が出ます。
- **忙しいビル**：会社の人が働いている間、ビルが少し揺れるので、誰が忙しいかひと目でわかります。設定でオフにできます。
- **プロジェクトのスキル**：プロジェクトのフォルダに独自のスキルがあれば、その会社の全員が使えます。同じ名前ならブループリントのスキルより優先されます。
- **スキルのスイッチ**：Codex と Claude 用に用意したスキルを使うかどうか選べるようになりました。
- **空港のチャットで好きなファイルを指定**：空港のチャットで `#` と入力すると、ホームフォルダを見てファイルを指定できます。
- **ログアウトの警告**：Claude や ChatGPT のサブスクリプションがログアウトされたら、アプリが知らせます。
- **修正**：アップデートで正しいバージョンがダウンロードされるようになりました。
