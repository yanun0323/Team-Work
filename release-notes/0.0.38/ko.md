## 새로운 기능

**더 깔끔해진 기본 블루프린트**
겹치던 역할 몇 개를 합쳤습니다. 기획자 둘은 하나의 **기능 기획자**가 되었고, 코드 리뷰어와 테스터는 하나의 **리뷰 & QA**가 되었습니다. 디자이너는 **UI 디자인 엔지니어**가 되었고, 이미지 같은 시각 자료를 맡는 **미디어 디자이너**가 새로 생겼습니다.

**기본 흐름은 끝나기 전에 결과를 확인합니다**
기능, 버그 수정, 코드 리뷰 흐름이 이제 확인 단계로 끝납니다. 무언가 맞지 않으면 그 단계에서 앞 단계로 작업을 되돌려 보낼 수 있습니다.

**공식 소스에 이름이 생겼습니다**
앱에서 블루프린트 소스를 나열하는 곳에 기본 소스는 repo 주소 대신 그냥 '공식 소스'라고 나옵니다.

## 수정

- 무언가를 숨긴 뒤 '숨기기' 버튼이 계속 눌린 것처럼 보이지 않습니다. 줄 그어진 눈이 이미 그걸 보여 줍니다.
