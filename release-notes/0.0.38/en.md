## What's new

**A tidier set of built-in blueprints**
We merged a few roles that overlapped. The two planners are now one **Feature Planner**, and the code reviewer and tester are now one **Review & QA**. The designer is now a **UI Design Engineer**, and there's a new **Media Designer** for images and other visual assets.

**Built-in flows check the work before they finish**
The Feature, Bug fix and Code review flows now end with a check. If something isn't right, that step can send the work back to the step before it.

**The official source has a name**
Where the app lists blueprint sources, the built-in one now just says "Official source" instead of a repo address.

## Fixes

- The "hide" button no longer looks pressed all the time once something is hidden. The crossed-out eye already shows that.
