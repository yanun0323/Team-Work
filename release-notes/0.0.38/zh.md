## 新功能

**內建員工藍圖更整齊**
我們合併了幾個重疊的角色。兩個規劃師合成一個**功能規劃師**，程式碼審查和測試合成一個**審查與 QA**。設計師改成 **UI 設計工程師**，還新增了負責圖片和其他視覺素材的**媒體設計師**。

**內建流程結束前會檢查成果**
功能、Bug 修正和程式碼審查流程現在都以一次檢查收尾。哪裡不對時，那一步可以把工作退回前一步。

**官方來源有名字了**
App 列出員工藍圖來源的地方，內建的那個現在直接寫「官方來源」，不再顯示 repo 網址。

## 修正

- 隱藏某個項目後，「隱藏」按鈕不會再一直看起來是按下去的樣子。劃掉的眼睛已經表示了這件事。
