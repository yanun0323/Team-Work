## 新機能

**社員が MCP ツールを使える**
`~/.team-work/mcp.json` に MCP サーバーを書くと（Claude Code や Cursor と同じ形式）、コマンドを実行できる社員がそのツールを使えます。書き方はヘルプにあります。

**社員の作業中に自分のコマンドを実行**
`~/.team-work/hooks.json` は Claude Code の hooks 形式で、メッセージを受け取ったときやツールを呼ぶときなどにあなたのコマンドを実行します。コマンドでツールの呼び出しを止め、理由を社員に伝えることもできます。
