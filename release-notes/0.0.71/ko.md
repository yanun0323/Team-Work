## 새 기능

**직원이 MCP 도구를 쓸 수 있어요**
`~/.team-work/mcp.json`에 MCP 서버를 적으면(Claude Code, Cursor와 같은 형식) 명령을 실행할 수 있는 직원이 그 도구를 받습니다. 쓰는 법은 도움말에 있습니다.

**직원이 일할 때 내 명령 실행**
`~/.team-work/hooks.json`은 Claude Code의 hooks 형식으로, 메시지를 받거나 도구를 부를 때 같은 순간에 내 명령을 실행합니다. 명령으로 도구 호출을 막고 직원에게 이유를 알려 줄 수도 있습니다.

## 수정

**회의 채팅의 토큰 수가 다시 보여요**
참여자가 많은 회의는 채팅 목록의 토큰 수를 줄 밖으로 밀어냈습니다. 이제 모서리에 그대로 있습니다.
