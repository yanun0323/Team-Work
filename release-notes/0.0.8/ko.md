## 새로운 기능

**섬에 낮과 밤이 생겼습니다**
- 섬에 시간대가 생겼습니다. 밤이 되면 일하는 회사의 창문에 불이 켜집니다.
- 설정 → **시간대**에서 시간이 흐르는 방식을 고르세요: 실제 시계, Minecraft(20분에 하루, 기본값), 항상 낮, 항상 밤.

**워크플로가 더 유연해졌습니다**
- 워크플로가 더 이상 '요구사항 정리'로 시작해 '인수 검토'로 끝날 필요가 없습니다. 들어오는 화살표가 없는 단계는 모두 시작점이며, 작업이 시작되면 함께 출발합니다.
- 실제로 시작된 갈래가 모두 끝나면 작업을 병합할 수 있습니다.
- 단계마다 **되돌려 보내기 가능**을 켜고 끌 수 있어, 어떤 단계가 작업을 다시 하도록 돌려보낼 수 있는지 정할 수 있습니다.
- 작업 단계에는 직원이 한 명입니다. 토론 단계에는 여러 명을 둘 수 있고, 그러면 회의가 됩니다: 첫 번째 사람이 진행하고, 여러분이 @한 사람이 차례로 답합니다.
- 기존 워크플로와 작업은 예전처럼 동작합니다.

**블루프린트 없는 직원**
- 블루프린트 대신 그 직원만의 사용자 지정 설정(프롬프트, 스킬, 도구)을 줄 수 있습니다.
- 빈 상태에서 시작하거나, **블루프린트에서 가져오기**로 복사해 고칠 수 있습니다. 복사본은 더 이상 원래 블루프린트를 따라가지 않습니다.
- 사용자 지정 설정은 그 직원만의 것이고, 직원이 떠나면 함께 사라집니다.

**새 작업은 여러분을 기다립니다**
- 새 작업은 **시작**을 누를 때까지 '할 일'에 머뭅니다. 직원이 만든 작업도 마찬가지입니다.

**설정**
- '대기 페이지 우선'이 **기본 페이지 자동 전환**으로 바뀌었습니다: 끄기, 채팅 우선, 작업 우선.

**작은 변경**
- 중국어에서 워크플로를 이제 '任務藍圖'라고 부릅니다.
- 바쁜 건물에서 날리는 돈이 진짜 지폐처럼 보입니다.
