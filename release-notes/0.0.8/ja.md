## 新機能

**島に昼と夜**
- 島に時間帯ができました。夜になると、仕事中の会社の窓に明かりがつきます。
- 設定 → **時間帯** で時間の進み方を選べます：実際の時計、Minecraft（20 分で 1 日、既定）、ずっと昼、ずっと夜。

**ワークフローがもっと自由に**
- ワークフローは「要件の明確化」で始まり「受け入れレビュー」で終わる必要がなくなりました。矢印が入ってこないステップはすべて開始点で、タスクが始まると一緒に動き出します。
- 実際に始まった枝がすべて終われば、タスクはマージできます。
- 各ステップで**差し戻し可**をオン・オフでき、どのステップが作業をやり直しに戻せるかを決められます。
- 作業ステップの社員は一人です。話し合いステップには複数置けて、ミーティングになります。最初の人が司会をし、@ した人が順番に答えます。
- 既存のワークフローとタスクはこれまでどおり動きます。

**ブループリントのない社員**
- ブループリントの代わりに、その社員だけのカスタム設定（プロンプト、スキル、ツール）を持たせられます。
- 白紙から始めるか、**ブループリントから読み込む**でコピーして手直しします。コピーはもとのブループリントに追従しません。
- カスタム設定はその社員だけのもので、社員がいなくなると一緒に消えます。

**新しいタスクはあなたを待ちます**
- 新しいタスクは**開始**を押すまで「未着手」で待ちます。社員が作ったタスクも同じです。

**設定**
- 「待っているページを優先」は**最初に開くページを自動で切り替え**になりました：オフ、チャット優先、タスク優先。

**小さな変更**
- 中国語表示では、ワークフローが「任務藍圖」と呼ばれるようになりました。
- 忙しいビルから飛ぶお金が、本物のお札らしくなりました。
