## 새로운 기능

**작업이 Node 프로젝트를 스스로 준비합니다**
프로젝트가 npm, pnpm, Yarn을 쓰고 잠금 파일이 있으면, 누군가 일을 시작하기 전에 Team Work가 작업 폴더에 패키지를 설치합니다. 뒤의 단계는 이미 있는 것을 다시 쓰고, 패키지 설정이 바뀔 때만 다시 설치합니다. Mac에는 여전히 Node와 패키지 관리자가 설치되어 있어야 합니다.

**준비가 실패하면 분명히 알려 줍니다**
패키지 설치가 실패하면 작업이 일을 시작하기 전에 멈추고 무엇이 잘못됐는지 알려 줍니다. 고친 뒤 다시 시도를 누르세요.

**더 조용한 섬**
섬 사람들이 더 이상 멈춰 서서 비행기를 바라보지 않습니다. 여전히 산책하고, 이야기하고, 손을 흔들고, 해변을 즐깁니다.
