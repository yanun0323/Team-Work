## 新機能

**タスクが Node プロジェクトを自分で準備します**
プロジェクトが npm、pnpm、Yarn を使っていてロックファイルがある場合、誰かが作業を始める前に、Team Work がタスクのフォルダにパッケージをインストールします。後のステップはそれを使い回し、パッケージの設定が変わったときだけやり直します。Mac には Node とパッケージマネージャーが入っている必要があります。

**準備に失敗したときははっきり伝えます**
パッケージのインストールがうまくいかないと、タスクは作業を始める前に止まり、何が悪かったかを伝えます。直してから再試行を押してください。
