## What's new

**Tasks get your Node project ready on their own**
If your project uses npm, pnpm or Yarn and has a lock file, Team Work now installs the packages in the task's folder before anyone starts working. Later steps reuse what's already there and only redo it when your package settings change. You still need Node and your package manager installed on your Mac.

**Clear message when setup fails**
If installing the packages doesn't work, the task stops before any work begins and tells you what went wrong. Fix it, then hit retry.

**Quieter island**
People on the island no longer stop to stare at the planes. They still stroll, chat, wave and enjoy the beach.
