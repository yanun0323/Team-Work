## 새로운 기능

**긴 명령은 백그라운드에서**
직원이 이제 빌드나 테스트 실행 같은 느린 명령을 백그라운드에서 시작하고 그동안 계속 일할 수 있습니다. 상태를 확인하거나, 기다리거나, 멈출 수 있습니다. 쉬고 있던 채팅은 명령이 끝나면 깨어나고, 작업 단계는 명령이 끝나기를 기다렸다가 인계합니다.

**읽기 전용 스크립트 도구로 더 많이(실험 기능)**
스크립트 도구로 웹 검색, 웹 페이지 읽기, 메모리 검색, 터미널 읽기도 할 수 있고, 여러 조회를 동시에 실행할 수 있습니다.

**더 나은 코드 검색**
의미로 코드를 검색한 결과가 더 깔끔해졌습니다: 아주 긴 줄이 목록을 채우지 않고, 기호만 있는 결과는 사라졌으며, 중국어·일본어·한국어 검색도 더 잘 맞습니다.

**가장 많이 함께 일한 동료 열 명**
프로필에 가장 많이 함께 일한 직원이 한 명이 아니라 열 명까지 나옵니다.

**친구의 최근 방문**
기지국의 친구마다 내 섬에 온 최근 열 번의 방문이 언제 왔고 얼마나 머물렀는지와 함께 보입니다.

## 수정

**더 분명한 OpenAI 오류**
OpenAI가 답변을 거절하면 이제 일반적인 오류 대신 잔액이 바닥났다거나 속도 제한에 걸렸다는 등의 이유가 보입니다.

**스킬을 쓴 답변 다시 시도**
스킬을 쓴 실패한 답변을 다시 시도해도 그때마다 스킬 지시가 또 붙지 않습니다.

**단계는 남은 명령을 기다립니다**
백그라운드 명령이 아직 돌고 있는데 단계가 멈추거나 교체되면, 작업은 그 명령이 끝날 때까지 기다렸다가 다음 단계를 시작하므로 두 실행이 같은 파일을 동시에 바꾸지 않습니다.
