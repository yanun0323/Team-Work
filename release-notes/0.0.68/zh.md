## 新功能

**長指令在背景執行**
員工現在可以把很慢的指令（例如建置或跑測試）放到背景，一邊等一邊繼續工作。他們可以查看它、等它或停止它。閒置的對話會在指令結束時醒來，任務步驟也會等它的指令跑完才交接。

**唯讀腳本工具能做更多（實驗功能）**
腳本工具現在也能搜尋網路、讀網頁、搜尋記憶和讀終端機，還能同時跑好幾個查詢。

**更好的程式碼搜尋**
依意思搜尋程式碼的結果更乾淨：超長的行不會再擠滿清單，只有符號的結果不見了，中文、日文和韓文的搜尋也更準。

**你最常合作的前十名同事**
個人檔案現在列出你最常合作的十位員工，不只一位。

**好友最近的拜訪**
基地台裡的每位好友，現在會顯示他最近十次來你島上的紀錄：什麼時候來、待了多久。

## 修正

**更清楚的 OpenAI 錯誤**
OpenAI 拒絕回覆時，現在會告訴你原因，例如餘額用完或達到速率限制，不再只是籠統的錯誤。

**重試用了技能的回覆**
重試一則用了技能的失敗回覆時，不會再每次都把技能的說明多加一遍。

**步驟會等還沒跑完的指令**
如果步驟被停止或替換時，它的背景指令還在跑，任務會等那個指令結束才開始下一步，不會有兩次執行同時改同一批檔案。
