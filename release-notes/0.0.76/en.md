## What's new

**Find version history in Help**
Open Help to switch between the guide, release notes for any version, and About. You no longer need to open Settings to check the app version.

## Fixes

**Invite a colleague without starting over**
When someone joins a chat, the model can reuse the part of the conversation it has already processed instead of reading it all again.

**Clearer character editing**
Long hair no longer pokes through hoodies. On wide screens, the character editor now covers the profile panel behind it.
