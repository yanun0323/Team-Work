## 新功能

**你自己的個人檔案和角色**
你的頭像現在在地圖右上角。點它可以看你在這座島上的成就：使用天數、完成的任務、對話、你說了多少話、token、費用，以及最常合作的員工。按「編輯」一件件替你的角色打扮：頭髮、鬍子、配件、上衣、下半身、鞋子，還有每一件的顏色，任何顏色都可以。改了就會自動儲存。你的名字也是配對的電腦會看到的名字，連同你的角色一起。基地台上的名字欄位拿掉了，改成點那裡的名字打開你的個人檔案。

**你也在島上**
你的角色現在和大家一起在自己的島上走動，晚上也不回家。個人檔案開著時，鏡頭會照「自動檢視」的設定跟著你：飛過去、只平移，或不動。

**鞋子**
大家現在有穿鞋了：皮鞋、運動鞋、靴子或夾腳拖，也可能打赤腳。新員工會隨機拿到一雙，已經雇的人保留原本的鞋子。

**地圖看得更多**
打開公司、機場、基地台、移民署或你的個人檔案時，左上角的時鐘不會再被藏起來。只有左邊打開頁面時才讓開，頁面關上就回來。說明仍然會清空整個畫面。

**不再有教學**
時鐘旁的清單拿掉了，連同它的設定和音效。之後會有新的方式來學習這個 App。
