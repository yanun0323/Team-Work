## What's new

**Meetings are easier to run**
- Starting a chat now means picking one person. Tick **Meeting** if you want to bring in more.
- If you don't @ anyone, only the chair answers. Before, everyone answered every time.
- Type **@All** when you do want everyone to answer. The chair still goes last.
- A **To** line above the message box shows who's going to answer as you type.
- Press **Invite others** at the top right to add someone mid-chat. They can read everything said so far, and the chat shows when they joined.
- When someone asks you a question, their name shows above the answer buttons, so you know who you're replying to.

**Employees can read your terminal**
- In a company chat, employees who can read files or run commands can now see what your company terminal has shown (the last 5,000 lines). They can't type into it.

**Mac app**
- Picking a folder for a new company opens the Mac's own folder window right away, with no more waiting for a dialog to show up.
- The app checks for updates every hour.

**Small fix**
- When a task skips its first step, that step now shows as done in the staffing list.
