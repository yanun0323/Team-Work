## 새로운 기능

**직원이 사람을 뽑고 설정을 바꿀 수 있습니다**
팀에 새 사람을 데려오라고 하면 직원이 직접 할 수 있습니다: 이름, 블루프린트, 모델을 고르면 새 사람이 바로 합류합니다. 여러 명을 한꺼번에 뽑을 수도 있습니다.

이미 팀에 있는 사람의 이름, 블루프린트, 모델, 사고 수준 같은 것을 바꾸려 하면 무엇이 바뀌는지 보여 주는 카드가 나타나고, 여러분이 허락하기 전에는 아무것도 바뀌지 않습니다. 여러 사람의 변경은 카드 한 장에 모입니다. 요청 중 하나라도 안 되는 것(없는 모델 등)이 있으면 아무것도 바뀌지 않습니다.

직원은 누구도 내보낼 수 없습니다. 그건 여전히 여러분이 정합니다.
