## What's new

**Friend islands**
The power tower now talks about islands instead of computers. The islands you've paired with are your friend islands, and the list shows each person's character face next to their name. If they haven't made a character yet, you'll see a dark block with a question mark.

**Adding a friend island is simpler**
Press "+ Add friend island" at the top of the power tower. Your pairing code appears right away, ready to copy, and below it you can paste the other island's code instead. There's no need to pick a side first anymore. Closing the page stops waiting.

**Who's on your island, and for how long**
The separate "On this island now" list is gone. A friend who is on your island right now moves to the top of the list and shows when they arrived and how long they've stayed. Reloading their page doesn't reset the time. The buttons to send a visitor away or block them have been removed. If you blocked someone before, you can still unblock them.

**Clearer access settings**
Each row now shows only the friend's name, status and Go, so it's clear what Go does. Click a row to open that island's page, where one line asks "Open my island to (name)" with Closed, View only or Can operate. To remove the friend, use the bin at the top right of that page. Newly paired islands now both start on View only. Before, the side that pasted the code started with the other side shut out.

## Fixes

**Gemini replies that call several tools at once**
When a Gemini model tried to use several tools in the same reply, every reply failed and kept retrying. Each tool call now runs on its own.

**Times shown in your app's language**
Arrival and block times on the power tower now use a 24-hour clock in the app's language, instead of your browser's format with AM and PM.
