## 새로운 기능

**친구 섬**
기지국이 이제 컴퓨터 대신 섬을 이야기합니다. 연결한 섬이 친구 섬이고, 목록에는 이름 옆에 각자의 캐릭터 얼굴이 보입니다. 아직 캐릭터를 만들지 않은 사람은 물음표가 있는 어두운 블록으로 보입니다.

**친구 섬 추가가 더 쉬워졌습니다**
기지국 위쪽의 '+ 친구 섬 추가'를 누르세요. 내 연결 코드가 바로 나타나 복사할 수 있고, 그 아래에 상대 섬의 코드를 대신 붙여 넣을 수도 있습니다. 더 이상 먼저 편을 고를 필요가 없습니다. 페이지를 닫으면 기다리기를 멈춥니다.

**누가 내 섬에, 얼마나 오래**
따로 있던 '지금 이 섬에 있음' 목록은 없어졌습니다. 지금 내 섬에 있는 친구는 목록 맨 위로 올라가고, 언제 왔고 얼마나 머물렀는지 보입니다. 상대가 페이지를 새로 고쳐도 시간은 초기화되지 않습니다. 방문자를 내보내거나 차단하는 버튼은 없어졌습니다. 전에 차단한 사람은 여전히 차단을 풀 수 있습니다.

**더 분명한 접근 설정**
각 줄에는 이제 친구의 이름, 상태, '이동'만 보여서 '이동'이 무엇을 하는지 분명합니다. 줄을 클릭하면 그 섬의 페이지가 열리고, '(이름)에게 내 섬 열기' 한 줄에서 '닫힘', '보기만', '조작 가능' 중에 고릅니다. 친구를 지우려면 그 페이지 오른쪽 위의 휴지통을 쓰세요. 새로 연결한 섬은 이제 양쪽 모두 '보기만'에서 시작합니다. 전에는 코드를 붙여 넣은 쪽이 상대를 막아 둔 채로 시작했습니다.

## 수정

**한 번에 여러 도구를 부르는 Gemini 답변**
Gemini 모델이 한 답변에서 여러 도구를 쓰려 하면 답변이 매번 실패하고 계속 다시 시도했습니다. 이제 도구 호출을 하나씩 따로 실행합니다.

**앱의 언어로 보이는 시간**
기지국의 도착 시간과 차단 시간이 이제 브라우저의 오전/오후 형식 대신 앱 언어의 24시간제로 보입니다.
