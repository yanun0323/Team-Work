## 새로운 기능

**쓰지 않는 모델 끄기**
공급자 페이지에서 모델을 클릭하면 끌 수 있고, 버튼 하나로 모두 끄거나(또는 다시 켤) 수 있습니다. 끈 모델은 모델을 고를 때 나타나지 않으므로 목록에는 실제로 쓰는 것만 남습니다. 끈 모델로 이미 일하는 사람은 예전처럼 계속 일합니다.

**입력해서 긴 목록 거르기**
선택지가 열 개가 넘는 목록에는 이제 맨 위에 필터 상자가 있습니다. 입력을 시작하면 바로 좁혀집니다. 모델은 공급자 이름으로, 사람은 블루프린트로 찾을 수 있습니다. 큰 회사에서는 일을 누군가에게 넘기는 메뉴와 회의 진행자를 바꾸는 메뉴에도 같은 필터가 있습니다.

## 수정

**API 키로 쓰는 OpenAI 모델의 사고 수준**
API 키로 비용을 내는 OpenAI 모델은 예전에 '기본값'만 고를 수 있었습니다. 이제 none부터 xhigh까지 실제 사고 수준을 고를 수 있습니다.
