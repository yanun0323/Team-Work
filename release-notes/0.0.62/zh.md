## 新功能

**關掉用不到的模型**
在供應商頁面上，點模型就能把它關掉，也可以用一個按鈕全部關掉（或全部打開）。關掉的模型在挑選模型時不會再出現，清單裡只剩你真正會用的。已經在用被關掉模型的人照常工作。

**打字篩選長清單**
任何超過十個選項的選單，最上面都多了一個篩選框，直接打字就能縮小範圍。可以用供應商名稱找模型，用員工藍圖找人。在大公司裡，「交給…」選單和更換會議主持人的選單也有同樣的篩選。

## 修正

**用 API 金鑰的 OpenAI 模型有思考等級了**
用 API 金鑰付費的 OpenAI 模型，以前只有「預設」可選。現在可以挑它們真正的思考等級，從 none 到 xhigh。
