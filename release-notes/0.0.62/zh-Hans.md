## 新功能

**关掉用不到的模型**
在供应商页面上，点模型就能把它关掉，也可以用一个按钮全部关掉（或全部打开）。关掉的模型在挑选模型时不会再出现，列表里只剩你真正会用的。已经在用被关掉模型的人照常工作。

**输入筛选长列表**
任何超过十个选项的菜单，最上面都多了一个筛选框，直接输入就能缩小范围。可以用供应商名称找模型，用员工蓝图找人。在大公司里，“交给…”菜单和更换会议主持人的菜单也有同样的筛选。

## 修复

**用 API 密钥的 OpenAI 模型有思考等级了**
用 API 密钥付费的 OpenAI 模型，以前只有“默认”可选。现在可以挑它们真正的思考等级，从 none 到 xhigh。
