## What's new

**Turn off the models you don't use**
On a provider's page, click a model to turn it off, or turn them all off (or back on) with one button. Turned-off models no longer show up when you pick a model, so the list only has the ones you actually use. Anyone already running on a model you turned off keeps working as before.

**Type to filter long lists**
Any pick-list with more than ten options now has a filter box at the top. Just start typing to narrow it down. You can find a model by its provider's name, and a person by their blueprint. In a big company, the menus for handing work to someone and changing who chairs a meeting have the same filter.

## Fixes

**Thinking levels for OpenAI models on an API key**
OpenAI models paid with an API key used to offer only "default". You can now pick their real thinking levels, from none up to xhigh.
