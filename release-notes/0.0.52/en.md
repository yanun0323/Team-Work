## What's new

**See how far a task has got from its card**
Task cards now show the step being worked on and how many of the flow's steps are done, like "Review · 3/6". When several steps run at once it reads "Review +1". For tasks run by an owner, a step only counts as done once the owner accepts it.

**More time per step in new companies**
A new company now gives each step up to 120 minutes before it times out, instead of 30. Existing companies keep their setting.

**A new skill from the official source**
The official source adds a "your-code-base" skill. Mention it with `$` to remind an employee that this project is theirs to keep working on, so anything left broken comes back to them later.

## Fixes

- The name tags on the map no longer get in the way: dragging, zooming and hovering work right through them, and clicking a tag still opens its company.
- When name tags overlap, the closer one now sits on top instead of a farther one covering it.
