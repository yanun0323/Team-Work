## What's new

**Animated GIFs from image generation**
- Employees can now ask for a short looping GIF instead of a still picture, and pick how many frames and how fast it plays.
- Most ChatGPT accounts can't make GIFs yet. When that happens, you now get a clear message saying so instead of a bare error code.

**Cleaner commit messages from tasks**
- When an employee finishes a step, the commit now uses a proper message written in your project's style, not the summary meant for you on screen.
