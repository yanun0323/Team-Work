## 新機能

**同じモデルを使う社員のモデルを一括で変更**
設定でモデルを選ぶと、島のどの社員が使っているかを確認し、まとめて別のモデルに切り替えられます。提供が終了したモデルからも切り替えられます。確定前に対象者を確認し、思考レベルを各自の設定のままにするか、全員で統一するかを選べます。

**次の作業を同僚に引き継ぐ**
グループチャットで最後に発言する社員は、次に必要な作業をほかの参加者に頼めます。あなたが改めて指示する必要はありません。会話の中で名前を挙げただけでは、その人に発言の順番は回りません。

## 修正

**既存のチャットにも社員の最新の設定を反映**
社員の名前、モデル、思考レベルを変更すると、次の返信から新しい設定が使われます。チャットを開き直す必要はありません。
