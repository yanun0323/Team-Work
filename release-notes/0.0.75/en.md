## What's new

**Switch everyone on the same model at once**
In Settings, pick a model to see who uses it across the island. You can move them all to another model, even if the old one is no longer offered. Before confirming, see who will change and choose whether to keep each person's thinking level or set one for everyone.

**Let a colleague take the next step**
In a group chat, the last person to reply can ask another participant to take care of a specific next step. You don't have to prompt them yourself. Just mentioning a name won't trigger a reply.

## Fixes

**Existing chats use the employee's current settings**
If you change an employee's name, model or thinking level, their next reply uses the new settings. There's no need to start a new chat.
