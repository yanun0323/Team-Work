## 새 기능

**무엇이 바뀌었는지 보기**
업데이트 후 Team Work가 그 버전의 새 내용을 보여 줍니다. 공항의 '정보'에서 언제든 각 버전의 설명을 읽을 수 있고, 설치 전 업데이트 창에도 먼저 나옵니다.

**더 넓은 상세 시트**
새 설정이나 각 시트 모서리의 버튼으로, 상세 시트를 회사 패널의 왼쪽 절반이 아니라 전체에 펼칠 수 있습니다. 아래 패널을 클릭하면 닫힙니다.

**WASD로 걷기**
프로필을 열어 카메라가 나를 따라오는 동안 W, A, S, D로 캐릭터를 걷게 할 수 있고, Shift를 누르면 뜁니다.

**스크립트 도구가 모든 도구 사용 (실험 기능)**
스크립트 도구(이전의 읽기 전용 스크립트 도구)가 이제 읽기용만이 아니라 직원의 모든 도구를 호출할 수 있어, 스크립트 하나로 여러 단계를 이어서 처리합니다. 내 답을 기다리거나 단계를 끝내는 도구는 여전히 쓸 수 없습니다.

**내 서버에 맞춘 컨텍스트 길이**
vLLM, SGLang, OpenRouter, llama.cpp, LM Studio의 모델은 이제 서버가 실제로 돌리는 컨텍스트 길이를 써서, 긴 대화를 알맞은 때에 줄입니다.

**직원이 옮겨도 기억은 그대로**
직원을 복사하면 기억도 함께 따라가고, 이민국으로 들어가거나 나와도 일과 채팅이 그대로 남습니다.

**설정에서 Debug 줄 켜기**
공항 설정에 앱 안에서 프레임 속도 줄을 보여 주는 스위치가 생겼습니다.

**스크롤하면 이전 메시지 불러오기**
채팅 맨 위까지 스크롤하면 이전 메시지가 저절로 나타나서, 버튼을 누를 필요가 없습니다.

**공식 블루프린트 이름과 순서**
'DevOps 엔지니어'는 'SRE 엔지니어'로, 'Matt Pocock'은 '범용 엔지니어'로 이름이 바뀌었습니다. 공식 블루프린트와 작업 흐름은 이제 정해진 순서로 나옵니다.

**커밋은 내 이름으로**
직원이 프로젝트에서 하는 커밋은 이제 내 git 이름과 이메일을 쓰고, 앱의 흔적을 남기지 않습니다. git이 내 정보를 모르면 직원이 먼저 설정해 달라고 요청합니다.

**회사 열기가 더 부드럽게**
채팅이 많은 회사를 열 때와 패널이 드나들 때 부담이 줄었고, 큰 화면에서 특히 차이가 납니다.

## 수정

**업데이트하면 최신 버전 설치**
백그라운드에서 미리 받아 둔 옛 업데이트를 설치해서, 설치하자마자 또 업데이트해야 하던 문제를 고쳤습니다.

**책임자가 이끄는 작업이 멈추지 않음**
책임자가 이끄는 작업에서 단계가 반려된 뒤 멈춰 버리는 일이 있었습니다. 이제 계속 진행됩니다.

**바다 물결이 매끄럽게 유지**
앱을 몇 시간 열어 두면 바다 물결이 네모난 무늬로 변했습니다. 이제 계속 매끄럽습니다.

**사고 수준은 한 번만 표시**
사고 수준 목록에 '기본값'이 두 번 나오지 않고, 그것으로 저장한 설정도 다시 제대로 불러옵니다.

**만든 것이 제자리에 표시**
채팅에서 직원이 만든 것은 이제 형식만 확인한 단계가 아니라 실제로 저장한 단계 아래에 나옵니다.
