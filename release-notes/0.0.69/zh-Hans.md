## 新功能

**看看改了什么**
更新之后，Team Work 会显示这一版的新内容；也可以随时在机场的“关于”读每一版的说明。安装前的更新窗口也会先列出来。

**更宽的子界面**
新增一个设置，也可以按每张子界面角落的按钮，让子界面铺满整个公司面板，不再只占左半边。点下面的面板就能收起来。

**用 WASD 走路**
打开个人资料、镜头跟着你的时候，可以用 W、A、S、D 让角色走动，按住 Shift 会跑。

**脚本工具能用所有工具（实验功能）**
脚本工具（原来的只读脚本工具）现在能调用员工所有的工具，不只是读取用的，一个脚本就能做完一连串的事。需要等你回答或会结束步骤的工具仍然不能用。

**上下文长度按你自己的服务器**
用 vLLM、SGLang、OpenRouter、llama.cpp 或 LM Studio 的模型，Team Work 现在会按服务器实际开的上下文长度，长对话会在对的时候压缩。

**员工搬家也带着记忆**
复制员工会一起带上他的记忆；把员工搬进或搬出移民局，他的工作和对话都会留着。

**在设置里打开 Debug 栏**
机场设置多了一个开关，可以在 App 里显示帧率那一栏。

**往上滚就加载更早的消息**
滚到对话最上面，更早的消息会自己出现，不用再按按钮。

**官方蓝图改名并排好顺序**
“DevOps 工程师”改名为“SRE 工程师”，“Matt Pocock”改名为“通用工程师”。官方蓝图和任务蓝图现在按固定顺序排列。

**commit 用你自己的名字**
员工在你项目里做的 commit，现在用你自己的 git 名字和邮箱，不会留下 App 的痕迹。git 不知道你是谁时，员工会请你先设置。

**打开公司更顺**
打开有很多对话的公司，以及面板滑进滑出，现在都更省力，大屏幕上特别明显。

## 修正

**更新会装到最新版**
Team Work 不会再安装之前在后台下载好的旧版更新，害你装完又要再更新一次。

**负责人主导的任务不再卡住**
负责人主导的任务在某个步骤被退回后，可能会卡住不动。现在会继续进行。

**海面波纹保持平顺**
App 开了几个小时后，海面的波纹会变成一格一格的方块。现在会一直保持平顺。

**思考等级只出现一次**
思考等级列表里的“默认”不会再出现两次，存过它的设置也能正常加载了。

**新建的东西显示在对的地方**
对话里员工创建的东西，现在显示在真正保存它的那一步下面，而不是只查了格式的那一步。
