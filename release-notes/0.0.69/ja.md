## 新機能

**何が変わったかを表示**
アップデートのあと、Team Work がそのバージョンの新しい内容を表示します。空港の「情報」からいつでも各バージョンの説明を読めます。インストール前のアップデート画面にも表示されます。

**詳細シートを広く**
新しい設定、または各シートの隅のボタンで、詳細シートを会社パネルの左半分だけでなく全体に広げられます。下のパネルをクリックすると閉じます。

**WASD で歩く**
プロフィールを開いてカメラが自分を追っているあいだ、W・A・S・D でキャラクターを歩かせられます。Shift を押すと走ります。

**スクリプトツールがすべてのツールを使える（実験機能）**
スクリプトツール（以前の読み取り専用スクリプトツール）が、読み取り用だけでなく社員のすべてのツールを呼べるようになり、ひとつのスクリプトで一連の作業をこなせます。あなたの返事を待つツールやステップを終えるツールは引き続き使えません。

**コンテキスト長を自分のサーバーに合わせる**
vLLM、SGLang、OpenRouter、llama.cpp、LM Studio のモデルでは、サーバーが実際に動かしているコンテキスト長を使うようになり、長い会話がちょうどよいタイミングで縮められます。

**社員は移っても記憶を持っていく**
社員をコピーすると記憶もいっしょに引き継がれます。入国管理局への出入りでも、仕事とチャットはそのまま残ります。

**設定から Debug バーを表示**
空港の設定に、アプリ内でフレームレートのバーを表示するスイッチが加わりました。

**スクロールで以前のメッセージを読み込む**
チャットのいちばん上までスクロールすると、以前のメッセージが自動で現れます。ボタンを押す必要はありません。

**公式ブループリントの名前と並び順**
「DevOps エンジニア」は「SRE エンジニア」に、「Matt Pocock」は「汎用エンジニア」に名前が変わりました。公式のブループリントとタスクフローは決まった順に並びます。

**コミットはあなたの名前で**
社員がプロジェクトで行うコミットは、あなた自身の git の名前とメールを使い、アプリの痕跡を残しません。git にあなたの情報がないときは、社員が設定をお願いします。

**会社を開くのがなめらかに**
チャットの多い会社を開くときや、パネルが出入りするときの負担が減りました。大きな画面で特に違いがわかります。

## 修正

**アップデートで最新版が入る**
バックグラウンドで先にダウンロードした古いアップデートをインストールしてしまい、すぐまた更新が必要になる問題を直しました。

**オーナー主導のタスクが止まらない**
オーナー主導のタスクで、ステップが差し戻されたあとに止まってしまうことがありました。今は続けて進みます。

**海の波紋がなめらかなまま**
アプリを数時間開いていると、海の波紋がブロック状の模様になっていました。今はなめらかなままです。

**思考レベルの表示は一度だけ**
思考レベルの一覧で「デフォルト」が二度出なくなり、それを保存した設定も正しく読み込めるようになりました。

**作ったものが正しい場所に表示される**
チャットで社員が作ったものは、形式を調べただけのステップではなく、実際に保存したステップの下に表示されます。
