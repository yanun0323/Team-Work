## 新功能

**看看改了什麼**
更新之後，Team Work 會顯示這一版的新內容；也可以隨時在機場的「關於」讀每一版的說明。安裝前的更新視窗也會先列出來。

**更寬的子介面**
新增一個設定，也可以按每張子介面角落的按鈕，讓子介面鋪滿整個公司面板，不再只佔左半邊。點下面的面板就能收起來。

**用 WASD 走路**
打開個人檔案、鏡頭跟著你的時候，可以用 W、A、S、D 讓角色走動，按住 Shift 會跑。

**腳本工具能用所有工具（實驗功能）**
腳本工具（原本的唯讀腳本工具）現在能呼叫員工所有的工具，不只是讀取用的，一個腳本就能做完一連串的事。需要等你回答或會結束步驟的工具仍然不能用。

**上下文長度照你自己的伺服器**
用 vLLM、SGLang、OpenRouter、llama.cpp 或 LM Studio 的模型，Team Work 現在會照伺服器實際開的上下文長度，長對話會在對的時候壓縮。

**員工搬家也帶著記憶**
複製員工會一起帶上他的記憶；把員工搬進或搬出移民局，他的工作和對話都會留著。

**在設定裡打開 Debug 列**
機場設定多了一個開關，可以在 App 裡顯示幀率那一列。

**往上捲就載入更早的訊息**
捲到對話最上面，更早的訊息會自己出現，不用再按按鈕。

**官方藍圖改名並排好順序**
「DevOps 工程師」改名為「SRE 工程師」，「Matt Pocock」改名為「通用工程師」。官方藍圖和任務藍圖現在照固定順序排列。

**commit 用你自己的名字**
員工在你專案裡做的 commit，現在用你自己的 git 名字和信箱，不會留下 App 的痕跡。git 不知道你是誰時，員工會請你先設定。

**打開公司更順**
打開有很多對話的公司，以及面板滑進滑出，現在都更省力，大螢幕上特別明顯。

## 修正

**更新會裝到最新版**
Team Work 不會再安裝之前在背景下載好的舊版更新，害你裝完又要再更新一次。

**負責人主導的任務不再卡住**
負責人主導的任務在某個步驟被退回後，可能會卡住不動。現在會繼續進行。

**海面波紋保持平順**
App 開了幾個小時後，海面的波紋會變成一格一格的方塊。現在會一直保持平順。

**思考等級只出現一次**
思考等級清單裡的「預設」不會再出現兩次，存過它的設定也能正常載入了。

**新建的東西顯示在對的地方**
對話裡員工建立的東西，現在顯示在真正儲存它的那一步下面，而不是只查了格式的那一步。
