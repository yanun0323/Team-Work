可移除；建立後在任務的詳細內容說明下方列出縮圖，點了會疊一張看原圖）、選流程和任務負責人（預設沿用上一個任務的負責人；只能選一位），下方的流程圖每個步驟下排著這次的負責員工，預設沿用同一條流程上一個任務的配置；整理需求和驗收由負責人執行，不能點；其他步驟點便條紙會疊一張員工名單，可勾選多人，同一人也可負責多步，按確定才會改；沒有人的步驟右上角會有紅色圓形驚嘆號；有任務負責人、每一步都有人、也有標題後才能按開始。任務的詳細內容也會畫出這次的人員配置，已經做完的步驟變成淡灰色；點這張流程圖會疊一張流程圖加上每個步驟的列表（步驟名稱也貼成便條紙，做完的步驟和圖上一樣變成淡灰色），點圖上的便條紙會捲到列表裡的那一步並短暫標出，列表裡的員工點了會疊上他的詳細內容，員工的詳細內容則列出他在進行中任務裡負責的步驟。檔案打開時像報紙貼上牆，關閉時反過來，從牆上撕起淡出；物件和名牌出現時從透明淡入，消失時淡出，物件的陰影也跟著漸漸變濃或變淡（低空雲的影子也是）。打開時地圖不能平移縮放；沒有關閉鈕，點地圖其他地方（包括打開的辦公室本身）收起（鍵盤可按 Esc），鏡頭回到打開前的位置。

主場景右上角最左邊是「告示牌」（告示牌圖示）：有任務在「待回覆」時，按鈕右上角會有紅色圓形，裡面的白色數字是所有公司待回覆的任務數（超過 99 顯示 99+），任務欄裡每張待回覆的任務便利貼右上角也有紅色圓形加白色驚嘆號；按下會在右半邊打開「所有任務」，樣式和公司檔案一樣但沒有大標題，整張是一條可以上下捲動的列表，每間公司一個區塊，上方是和公司檔案相同的頭（郵票、名稱、專案位置和目標分支，下面沒有分隔線），下方是它的任務欄（待辦、進行中、待回覆、完成，包括「＋ 新增任務」），畫面太窄時只有任務欄能左右捲動，公司名稱不動；點任務或新增任務會和在公司檔案裡一樣在左上疊上詳細內容。收起的方式和設定一樣，點地圖任何地方（包括大樓）只會收起，不會打開公司。「告示牌」右邊是「＋ 新公司」：按下後先在地圖上選位置，一塊大樓用地大小的虛線框跟著游標走、對齊格子，陸地或海上都可以放；離其他大樓用地太近（少於兩格草地）或離岸太遠（超過 24 格海）時框變紅、不能放。按鈕變成「取消」，按它或 Esc 才結束選位，點其他地方不會取消。點一下放好後，鏡頭把它置中在左半邊，右半邊貼上一張「新公司」的紙，用地上同時蓋出一棟剛成立時大小的大樓預覽（一層、4×4 格）。紙最上方是「外觀」：郵票圖示和款式名稱（玻璃大樓、紅磚樓、工作室、工業倉庫、木屋、石造、科技大樓、東方樓閣、裝飾藝術、垂直森林、地中海別墅），右邊的骰子鈕會隨機換一套款式和配色，地圖上的預覽跟著變；每次選好位置都先隨機一套。接著填專案位置（右邊的資料夾鈕會打開檔案瀏覽器選資料夾；網頁拿不到完整路徑，所以放在原本填的資料夾旁邊，沒填就放在 `~/code/` 下）、名稱（預設取資料夾名）和目標分支（已知的 repo 從它的分支裡選），按「建立」後大樓蓋在選的位置並直接打開公司檔案；點地圖其他地方或按 Esc 收起這張紙、回到選位。島嶼的陸地依各大樓用地往外長，放在海上的大樓會自動拉出一條相連的陸地接回島上，被圍住的海會填成陸地；已有的大樓都留在原位不動。公司檔案「設定」頁籤有名稱、目標分支和「公司規章」（專案提示詞：這間公司每位員工都會收到的共同指示，接在藍圖自己的提示詞之上；多行文字框，改了立刻生效），接著是子任務逾時、任務費用上限和失敗重試，最下方有紅色的「解散公司」，按下會在左上貼上一張確認的紙：寫著有幾位員工、幾個未完成的任務，一個「同時刪除本地檔案」的勾選（預設不勾，下面寫著專案位置），再按紅色的「解散公司」才會執行：公司連同員工、流程、任務一起移除（藍圖保留），公司檔案收起，其他大樓的位置和外觀不變；它的陸地留著，原本的用地變回草地、長出樹，之後也可以在那裡蓋新公司。原型沒有真的檔案，勾了也不會刪任何東西。

主場景右上角依序是「＋ 新公司」「編輯地圖」、問號和飛機（設定）。按「編輯地圖」進入編輯模式（按鈕變成「完成」，其他按鈕隱藏，鏡頭拉遠）：點一間公司（大樓或名牌）選取它，大樓變暗、名牌浮起，再出現一塊跟著游標的用地虛線框，規則和新公司一樣，只是不和自己比；點下去公司就連同大樓搬過去，原本的地留著（變回草地、長出樹）；放回原處則什麼都不變。機場不能選取、也不能搬；再點同一間取消選取、點另一間換選，點不能放的地方或按 Esc 取消選取；沒有選取時按「完成」或 Esc 結束編輯。只剩一間公司時，只能搬到原本的地附近，讓島連在一起。問號按鈕會在畫面中間打開「使用說明」，四周露出地圖，樣式和貼上、撕下的動畫都和 drawer 一樣：左邊列出項目（開始使用、地圖、公司、任務、流程、員工、員工藍圖、模型供應商，上下方向鍵切換），右邊先放一張那個部分的實際畫面截圖（太高的只露出上半部），再接說明；和 drawer 一樣沒有關閉鈕，點地圖或按 Esc 關閉，焦點回到問號按鈕。窄螢幕上項目改排在上方、可左右捲動。截圖放在 `src/help/`，介面改了要重拍。

主場景右上角的飛機按鈕（或點地圖上的機場）會在右半邊打開設定 drawer（點機場時鏡頭會飛到機場、把它置中在左半邊，收起後飛回原本的視角；用飛機按鈕打開時鏡頭不動），樣式和公司檔案一樣：標題是「Mho Company」，下面是版本號，頁籤有「模型供應商」「員工藍圖」「設定」「關於」（預設打開模型供應商）。「設定」是全域參數，改了立刻生效，並存在瀏覽器裡（重新整理後還在）：「功能」區塊有「任務紀錄排序」（下拉選單：新的在最上面〔預設〕、新的在最下面，套用到任務、子任務和員工「最近的工作」的紀錄；在另一個分頁改的也會同步過來）；「遊戲物件」區塊有五個勾選（預設都打勾）：「細節」關掉後不畫小裝飾（桌上的鍵盤和小東西、盆栽、書架上的書、路燈、花圃上的花、機場的屋頂空調、跑道燈、航廈窗框和風向袋、海面的浪花泡沫和風紋；長椅、沙發、咖啡機這些人會用到的照畫），「陰影」關掉後不畫陰影，「地圖民眾」關掉後不畫公司外面的路人，「飛機動畫」關掉後飛機停在停機位不起降，也不會有飛機飛越小島，「雲朵」關掉後不畫低空雲和雲影。「模型供應商」列出所有供應商（類型、連線方式、模型數）和「＋ 新增模型供應商」：點供應商會在左上貼上詳細內容（類型、連線方式、API 位址和只顯示末四碼的 API Key、模型、使用中的員工），右上角有編輯和刪除；還有員工（任何公司）使用這個供應商的模型時不能刪除，刪除也要再按一次「確定刪除」。新增時選類型（Anthropic、OpenAI、Google Gemini、OpenAI 相容），模型由供應商提供，不用輸入。Anthropic 和 OpenAI 可以選「API Key」或「Claude 訂閱」／「ChatGPT 訂閱」：訂閱要按「登入」（原型裡直接當作登入成功），沒登入就按新增會提示「請先登入」；API Key 方式填 API 位址（OpenAI 相容必填，其他留空用官方位址）和 API Key（只保存末四碼）。編輯可改名稱、連線方式和位址，類型不能改；API Key 留空就沿用原本的。「關於」有 GitHub、Discord、X、Threads、Buy Me a Coffee 的連結（另開分頁），每個做成不同顏色、略微歪斜的紙質便利貼，上面有社群圖示（取自 Simple Icons，CC0），滑過會擺正浮起；下面是感謝名單。「員工藍圖」列出所有藍圖和「＋ 新增員工藍圖」：點藍圖會在左上貼上它的詳細內容（使用中的員工列出所有公司的人），右上角有編輯和刪除：編輯會疊上一張和新增相同的表單，按「儲存」才生效；還有員工（任何公司）使用這個藍圖時不能刪除，刪除也要再按一次「確定刪除」。藍圖的技能可以來自本機資料夾或多個 GitHub repo，詳細內容的「來源」寫藍圖本身的 repo（或「本地 YAML 配置」），「備註」是作者的說明，「技能」依來源分組列出載入的 skill（沒指定就是「全部」，排除的加刪除線）；每個 GitHub 來源都標出狀態：找不到上游、更新失敗（附時間和原因，仍使用舊版本）、有新版本或已是最新（附上次更新成功的時間）。列表上有問題的藍圖會寫「N 個來源有問題」。上游有新版本時，開啟自動更新的藍圖會嘗試更新，可能失敗。「工具」列出允許的工具，只會是讀取檔案、寫入檔案、網路搜尋、執行指令這四種，檢視時不能修改；從 GitHub 新增的藍圖預設只允許讀寫檔案。點新增會貼上一張表單：最上面是「樣式」，顯示藍圖圖示，旁邊的骰子鈕會隨機換一個（髮型、眼睛、眉毛、鼻子、嘴巴、鬍子和配件）；來源選 GitHub 或 YAML。GitHub：Repo 可以打 `owner/repo`，也可以貼 GitHub 網址，網址裡的 branch、tag 或 commit 會自動填進「版本」；版本留空就用預設分支（main 或 master）。名稱預設取 repo 名，不能空白。YAML：在輸入框寫出整份藍圖（已預填範例，Tab 會縮排），格式見專案根目錄的 `blueprint_sample.yaml`：`name` 必填，`prompt`、`comment`、`skills`、`tools` 可省略（預設為空），沒有 `provider` 和 `model`（模型由每位員工自己選）；`skills` 的每一項是 `path`（本機的 `~/.agents/` 或 `~/.agents/skills/`）或 `repo`（`owner/repo` 或網址，可加 `ref`，預設 master，沒有就 main），都可加 `include`（預設全部）和 `exclude`（預設沒有）；`tools` 只能是 `read_file`、`write_file`、`web_search`、`run_command`。內容有誤時會指出第幾行、哪裡錯。按「新增」才會加入。和公司檔案一樣疊紙、按 Esc 一層層收起；點地圖任何地方（包括大樓）只會收起設定，不會打開公司。打開期間地圖不能平移縮放、飛機按鈕隱藏，收起後飛機按鈕回來並取得焦點。

## 執行

在專案根目錄執行：

```sh
make dev
```

首次執行會安裝套件。開啟 http://localhost:5173。

這是前端假資料模擬，不執行 Agent、不操作 Git。重新整理會重設模擬，不保存修改。

## 檢查與建置

```sh
npm --prefix frontend test           # 模擬器與城鎮版面測試
npm --prefix frontend run typecheck  # 型別檢查
npm --prefix frontend run build      # 建置到 frontend/dist/
npm --prefix frontend run preview    # 預覽建置結果，port 5173
```

`src/` 底下是畫面與樣式；`src/core/` 是公司資料的模擬器（領域模型、假資料、執行模擬）。

three.js 的建置檔較大，建置時可能出現超過 500 kB 的提醒。
